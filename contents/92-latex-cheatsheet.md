# 数式記法早見表

本文中の数式は `$…$`、独立した行に置く数式は `$$…$$` で囲みます。中身には **LaTeX の記法も、見たままの素の表記も使えます**。どちらも同じように組まれるので、書きやすいほうを選んでください。

数式の基本や、バッククォートで囲んだときの扱いは「執筆チュートリアル」と「便利な拡張記法」で説明しています。ここでは、書きたい形から記法を探せるように並べました。

## 基本の構造

| 書きたいもの | 素のまま書く | LaTeX で書く | 結果 |
| :--- | :--- | :--- | :--- |
| 上付き | ``x²`` ``10⁻³⁴`` | ``x^2`` ``10^{-34}`` | $x^2$　$10^{-34}$ |
| 下付き | ``H₂O`` ``a₁`` | ``H_2O`` ``a_1`` | $H_2O$　$a_1$ |
| 冪乗（2 文字以上） | ``2^(1/3)`` ``a^(p-1)`` | ``2^{1/3}`` ``a^{p-1}`` | $2^{1/3}$　$a^{p-1}$ |
| 根号 | ``√2`` ``√(x+1)`` | ``\sqrt{2}`` ``\sqrt{x+1}`` | $\sqrt{2}$　$\sqrt{x+1}$ |
| 分数 | ``(a+b)/2`` | ``\frac{a+b}{2}`` | $\frac{a+b}{2}$ |
| 総和 | ``Σ(i=1 to n)`` | ``\sum_{i=1}^{n}`` | $\sum_{i=1}^{n}$ |
| 積分 | ``∫[0, 1]`` | ``\int_{0}^{1}`` | $\int_{0}^{1}$ |
| 極限 | ``lim(n→∞)`` | ``\lim_{n \to \infty}`` | $\lim_{n \to \infty}$ |
| 剰余 | ``a mod n`` | ``a \bmod n`` | $a \bmod n$ |

:::{.note}
根号が掛かるのは**直後のひとかたまり**です。``√x+1`` は「√x に 1 を足す」と読まれます。`x+1` 全体に掛けるには ``√(x+1)`` と括弧で囲みます。分数も ``\frac{a+b}{2}`` のように、分子の範囲を明示してください。
:::

:::{.note}
大文字の「（なし）」は、対応する LaTeX コマンドがないことを示します。ラテン文字の大文字と同じ形なので、専用のコマンドは用意されていません。たとえば ``\Alpha`` と書いても、そのまま文字列として表示されます。

:::

## 記号

次の記号も直接入力できます。表では、実際の字と対応する LaTeX コマンドを並べました。

| 分類 | 記号と LaTeX のコマンド |
| :--- | :--- |
| 四則・演算 | + ``+``　- ``-``　× ``\times``　÷ ``\div``　⋅ ``\cdot``　± ``\pm``　∓ ``\mp``　∘ ``\circ`` |
| 等号・不等号 | = ``=``　≠ ``\neq``　< ``<``　> ``>``　≤ ``\leq``　≥ ``\geq``　≪ ``\ll``　≫ ``\gg`` |
| 近似・比例 | ≈ ``\approx``　≡ ``\equiv``　∼ ``\sim``　∝ ``\propto`` |
| 集合 | ∈ ``\in``　∉ ``\notin``　⊂ ``\subset``　⊃ ``\supset``　∪ ``\cup``　∩ ``\cap``　∅ ``\emptyset`` |
| 論理・限量 | ∀ ``\forall``　∃ ``\exists``　⊥ ``\perp``　∞ ``\infty`` |
| 矢印 | → ``\to``　← ``\leftarrow``　↦ ``\mapsto``　⇒ ``\Rightarrow``　⇐ ``\Leftarrow``　⇔ ``\Leftrightarrow`` |
| 大型演算子 | ∑ ``\sum``　∏ ``\prod``　∫ ``\int``　∮ ``\oint`` |
| 微分・その他 | ∂ ``\partial``　∇ ``\nabla``　⟨ ``\langle``　⟩ ``\rangle``　… ``\ldots`` |

:::{.note}
`=` `<` `>` `+` `-` は記号をそのまま書きます。専用のコマンドは不要です。全角の ＝ ＋ − も、半角に直してから組まれます。
:::

## 関数

関数名は**そのまま書いて構いません**。LaTeX ではコマンドとして書きます。

```markdown
$sin²θ + cos²θ = 1$                 素のまま
$\sin^2\theta + \cos^2\theta = 1$   LaTeX
```

表示結果は次のようになります。{.aki}

$\sin^2\theta + \cos^2\theta = 1${.aki}

対応している関数名は次の 38 種です。いずれも素の表記と LaTeX の両方で書けます。{.aki}

| 分類 | 関数名 |
| :--- | :--- |
| 三角関数 | ``sin`` ``cos`` ``tan`` ``sec`` ``csc`` ``cot`` |
| 逆三角関数 | ``arcsin`` ``arccos`` ``arctan`` |
| 双曲線関数 | ``sinh`` ``cosh`` ``tanh`` ``coth`` |
| 指数・対数 | ``exp`` ``log`` ``ln`` ``lg`` |
| 極限 | ``lim`` ``liminf`` ``limsup`` ``injlim`` ``projlim`` ``varliminf`` ``varlimsup`` ``varinjlim`` ``varprojlim`` |
| 最大・最小・上限・下限 | ``max`` ``min`` ``sup`` ``inf`` |
| 代数・幾何 | ``det`` ``dim`` ``deg`` ``ker`` ``hom`` ``gcd`` ``arg`` |
| 確率 | ``Pr`` |

:::{.note}
一覧にない関数名は、`\operatorname{…}` で囲んでください。たとえば行列の階数 `rank`（行列に含まれる 1 次独立な行・列の最大数）は一覧にありません。``\operatorname{rank}(A)`` と書けば `rank` がひとまとまりの関数名として組まれます。囲まないと 1 文字ずつ別々の変数として扱われ、`r × a × n × k` の積のように読めてしまいます。
:::

## ディスプレイ数式にするもの

総和・積分・極限・大きな分数は、**ディスプレイ数式（`$$…$$`）にすると読みやすくなります**。本文中に置くと、上下限が記号の横へ寄り、式の高さも圧縮されて読みにくくなります。

```markdown
$$\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$$

$$\lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = e$$
```

表示結果は次のようになります。{.aki}

$$\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$$

$$\lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = e$$

複数行を揃えたいときは、言語に `math` と書いたコードブロックの中へ 1 行ずつ書きます。**各行を `$$` で囲む必要はありません**。`=` や `≈` の位置で自動的に揃います（GitHub と同じ書き方です）。

````markdown
```math
cos θ = 1 - θ²/2! + θ⁴/4! - θ⁶/6! + ...
sin θ = θ - θ³/3! + θ⁵/5! - θ⁷/7! + ...
```
````

表示結果は次のようになります。{.aki}

```math
cos θ = 1 - θ²/2! + θ⁴/4! - θ⁶/6! + ...
sin θ = θ - θ³/3! + θ⁵/5! - θ⁷/7! + ...
```

言語名のないコードブロックも、中身が数式だと判定されれば同じように組まれます。判定方法は「便利な拡張記法」で説明しています。

## Kindle での見え方

Kindle では、画像の大きさを本文の文字サイズに合わせて変えることができません。そのため、**インライン数式はできるだけテキストに変換**して埋め込みます。読者が文字を大きくしたとき、数式も一緒に大きくなります。

- 上の表にある記法は、ほぼすべてテキストになる（``√2``・``∑`` と上下限・``(a+b)/2`` など）
- テキストで表しようがない式（2 段重ねの上付き ``x^{y^z}``、入れ子の分数など）だけが画像のまま残る。同じ式を素の表記で書けば、書いたとおりの文字で表示され、追従する
- **ディスプレイ数式は画像のまま**。総和や積分の組版を保つためで、行を占有するので崩れない
