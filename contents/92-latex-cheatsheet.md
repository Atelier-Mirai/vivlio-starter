# 数式記法早見表

数式は `$…$`（インライン）と `$$…$$`（別行立て）で囲んで書きます。中身は **LaTeX の記法でも、見たままの素の表記でも構いません**。どちらで書いても同じ結果になります。

書き方の基本と、バッククォートで囲んだ数式の扱いは「執筆チュートリアル」と「便利な拡張記法」で解説しました。ここでは**逆引きの早見表**として、書きたい形から記法を引けるようにまとめます。

## 基本の構造

| 書きたいもの | 素のまま書く | LaTeX で書く | 結果 |
| :--- | :--- | :--- | :--- |
| 上付き | ``x²`` ``10⁻³⁴`` | ``x^2`` ``10^{-34}`` | $x^2$　$10^{-34}$ |
| 下付き | ``H₂O`` ``aₙ`` | ``H_2O`` ``a_n`` | $H_2O$　$a_n$ |
| 冪乗（2 文字以上） | ``2^(1/3)`` ``a^(p-1)`` | ``2^{1/3}`` ``a^{p-1}`` | $2^{1/3}$　$a^{p-1}$ |
| 根号 | ``√2`` ``√(x+1)`` | ``\sqrt{2}`` ``\sqrt{x+1}`` | $\sqrt{2}$　$\sqrt{x+1}$ |
| 分数 | ``(a+b)/2`` | ``\frac{a+b}{2}`` | $\frac{a+b}{2}$ |
| 総和 | ``Σ(i=1 to n)`` | ``\sum_{i=1}^{n}`` | $\sum_{i=1}^{n}$ |
| 積分 | ``∫[0, 1]`` | ``\int_{0}^{1}`` | $\int_{0}^{1}$ |
| 極限 | ``lim(n→∞)`` | ``\lim_{n \to \infty}`` | $\lim_{n \to \infty}$ |
| 剰余 | ``a mod n`` | ``a \bmod n`` | $a \bmod n$ |

:::{.note}
根号は**直後のひとかたまり**に掛かります。``√x+1`` は「√x に 1 を足す」という意味になるので、全体に掛けたいときは ``√(x+1)`` と括弧で括ってください。分数も同じで、``\frac{a+b}{2}`` のように**どこまでが分子か**を明示します。
:::

## 関数

関数名は**そのまま書けば立体（斜体でない字）で組まれます**。LaTeX ではコマンドとして書きます。

```markdown
$sin²θ + cos²θ = 1$        素のまま
$\sin^2\theta + \cos^2\theta = 1$   LaTeX
```

$\sin^2\theta + \cos^2\theta = 1${.aki}

使えるのは次の 19 種です。{.aki}

``sin`` ``cos`` ``tan`` ``arcsin`` ``arccos`` ``arctan`` ``sinh`` ``cosh`` ``tanh`` ``sec`` ``csc`` ``cot`` ``log`` ``ln`` ``exp`` ``det`` ``gcd`` ``max`` ``min``

## 別行立てで書くもの

総和・積分・極限・大きな分数は、**別行立て（`$$…$$`）で書いてください**。インラインに置くと、TeX の決まりで上下限が記号の横へ寄り、高さも圧縮されて読みにくくなります。

$$\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$$

$$\lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = e$$

複数行を揃えたいときは、言語を書かないコードブロックの中に 1 行ずつ書けば、関係演算子の位置で揃います。

````markdown
```
cos θ = 1 - θ²/2! + θ⁴/4! - θ⁶/6! + ...
sin θ = θ - θ³/3! + θ⁵/5! - θ⁷/7! + ...
```
````

```
cos θ = 1 - θ²/2! + θ⁴/4! - θ⁶/6! + ...
sin θ = θ - θ³/3! + θ⁵/5! - θ⁷/7! + ...
```

## Kindle での見え方

Kindle では、画像を本文のフォントサイズへ追従させる手段がありません。そこで**インライン数式は本文テキストへ変換**して埋め込みます。読者が文字を大きくすれば、数式も一緒に大きくなります。

- 上の表にある記法は、ほぼすべてテキストになる（``√2``・``∑`` と上下限・``(a+b)/2`` など）
- テキストで表しようがない式（2 段重ねの上付き ``x^{y^z}``、入れ子の分数など）だけが画像のまま残る。同じ式を素の表記で書けば、書いたとおりの文字で表示され、追従する
- **別行立ての数式は画像のまま**。総和や積分の組版を保つためで、行を占有するので崩れない
