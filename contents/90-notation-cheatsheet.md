# 記法早見表

:::{.chapter-lead}
<!-- no-lint -->
原稿を書いていて「この表現はどう書くのだったか」と迷ったときに、やりたいことから記法を探せる早見表です。細かな決まりや実例は「解説章」列からたどれます。表中の「執筆」は @ch-markdown-tutorial、「拡張」は @ch-extensions、「図版」は @ch-figures、「相互参照」は @ch-cross-reference、「索引」は @ch-index-glossary、「データ展開」は @ch-querystream を指します。
:::

### 文章の基本

:::{.long-table}
| やりたいこと | 書き方 | 解説章 |
|:---|:---|:---|
| 見出しを付ける | `# 見出し`（`#` の数 1〜6 でレベル） | 執筆 |
| 太字にする | `**太字**` | 執筆 |
| 斜体にする | `*斜体*` | 執筆 |
| 取り消し線を引く | `~~取り消し線~~` | 執筆 |
| ルビ（振り仮名）を振る | `{相対性理論\|そうたいせいりろん}` | 執筆 |
| キーボードのキーを示す | `〘Ctrl〙 + 〘S〙`・`<kbd>Ctrl + S</kbd>` | 拡張 |
| 改行する | 行末で改行するだけ（ハード改行）。`<br>` でも可 | 執筆 |
| 段落を分ける | 空行で区切る | 執筆 |
| 記号をそのまま表示する | `\*` のように `\` を前置してエスケープ | 執筆 |
| 改ページする | `---` だけの行を置く | 執筆 |
:::

### リスト

:::{.long-table}
| やりたいこと | 書き方 | 解説章 |
|:---|:---|:---|
| 箇条書き | `- 項目`（字下げで入れ子。マーカーは ● ○ ・ と自動変化） | 執筆 |
| 番号付きリスト | `1. 項目` | 執筆 |
| 英字・ローマ数字の番号 | `a.` `(A)` `i)` などのマーカーで書き始める（fancy list） | 執筆 |
| チェックボックス付きの一覧 | `- [ ] 未了` / `- [x] 済み`（タスクリスト） | 執筆 |
| 複合番号（1.1 / 1.2） | 番号リストを `:::{.outline-list}` で囲む | 拡張 |
| 用語と説明を並べる | 用語の次の行に `: 説明`（定義リスト） | 執筆 |
| ▶ 付きの補足リスト（青コメ） | `- ▶ 補足` | 拡張 |
| ❶ 付きの手順リスト（赤コメ） | `- ❶ 手順` | 拡張 |
:::

### コードとターミナル

:::{.long-table}
| やりたいこと | 書き方 | 解説章 |
|:---|:---|:---|
| インラインコード | バッククォート 1 つで囲む | 執筆 |
| コードブロック | バッククォート 3 つのフェンスで囲み、言語名を指定（例: `ruby`） | 執筆 |
| ファイル名を表示する | 言語名に続けて `ruby:app.rb` | 執筆 |
| 行番号を途中から始める | `ruby:foo.rb#L5` | 拡張 |
| 外部ファイルを取り込む | フェンスに `include:sample.rb`（`:10-20` で範囲指定） | 拡張 |
| コメント行を強調する | コメント内に `[!]` を書く（例: `# [!] 注目`） | 拡張 |
| ターミナル入力を示す | `:::{.terminal}` で囲み、`$ コマンド` を書く | 拡張 |
| 実行結果・出力例を示す | `:::{.output}` で囲む | 拡張 |
| コードと表示例を左右に並べる | 二つのブロックを `::::{.side-by-side}` で囲む（中の囲みより外側のコロンを多く） | 拡張 |
:::

### 表

:::{.long-table}
| やりたいこと | 書き方 | 解説章 |
|:---|:---|:---|
| 表を作る | 縦棒で列を区切り、`---` の行でヘッダーと本体を分ける | 執筆 |
| セルの配置を変える | 区切り行を `:--`（左）`:-:`（中央）`--:`（右）にする | 執筆 |
| セルを横に結合する | 結合したいセルを空にして縦棒を続ける（`\|\|`） | 拡張 |
| ヘッダーを複数行にする | 区切り行の上に複数の行を書く | 拡張 |
| 見出しの行を出さない | 見出しの行のセルをすべて空にする（`\| \| \|`） | 執筆 |
| セル内に縦棒を書く | 縦棒の前にバックスラッシュを置いてエスケープする | 拡張 |
| 行の多い長い表 | `:::{.long-table}` で囲む（文字が小さめに詰まる） | 拡張 |
| 横に広い表を回転する | `:::{.rotate-table}`（`scale` `shift-y` で微調整） | 拡張 |
:::

### 画像・図

:::{.long-table}
| やりたいこと | 書き方 | 解説章 |
|:---|:---|:---|
| 画像を貼る | `![代替テキスト](画像.png)` | 執筆 |
| サイズ・配置を変える | `![](画像.png){width=50% align=center}` | 図版 |
| キャプションと図番号を付ける | 画像の直前の行に `** タイトル @ラベル **` | 図版 |
| 画像の周囲を切り落とす | `![](画像.png){crop="30 100"}` | 図版 |
| 画像の余白を詰めて大きく載せる | `![](画像.png){trim=on}` | 図版 |
| 画像の枠を外す | `![](画像.png){border=off}`（単独で置いた画像には既定で枠が付く） | 図版 |
| 写真をグリッドで並べる | `:::{.pictures}` の中に画像を並べる | 図版 |
| 画像を 2 枚横に並べる | `:::{.image-group}` | 図版 |
| 画像と本文を横に並べる | `:::{.img-text}`（`.img-text2` `.text2-img` など比率違いあり） | 図版 |
| 本文を画像に回り込ませる | `:::{.sideimage-right}` / `:::{.sideimage-left}` | 図版 |
| スクリーンショットに注釈を描く | `:::{.showcase}` の中に `rect:1 …` / `pointer:2 …` を書く | 図版 |
| 罫線図・アスキーアートを載せる | `:::{.diagram}` で囲む（行番号なしの囲み枠） | 拡張 |
| フローチャートなどの図を描く | フェンスの言語名に `mermaid` を指定して図ソースを書く | 図版 |
:::

### リンク・脚注・数式

:::{.long-table}
| やりたいこと | 書き方 | 解説章 |
|:---|:---|:---|
| リンクを張る | `[テキスト](URL)` | 執筆 |
| URL をそのままリンクにする | `<https://example.com>` | 執筆 |
| 同じ URL を何度も使う | `[テキスト][id]` と、別行に `[id]: URL`（参照リンク） | 執筆 |
| 脚注（参照型） | 本文に `[^id]`、文末に `[^id]: 内容` | 執筆 |
| 脚注（インライン） | `^[短い補足]` | 執筆 |
| 数式を書く | インラインは ``$a^2 + b^2 = c^2$``、ディスプレイ数式は ``$$…$$`` | 執筆 |
| 数式を素のまま書く | ``x²`` ``√(x+1)`` ``2^(1/3)`` ``Σx²`` のように見たままで書ける（LaTeX 不要） | 執筆 |
| 数式だと明示する | フェンスの言語名に `math` を指定（中身を判定せずディスプレイ数式にする） | 拡張 |
| 数式をコードのまま見せる | バッククォートを 2 つ重ねる（``` ``√n`` ```）。バッククォート 1 つだと数式として組まれる | 拡張 |
:::

### 囲み枠・注記

:::{.long-table}
| やりたいこと | 書き方 | 解説章 |
|:---|:---|:---|
| 章の導入文 | `:::{.chapter-lead}` | 拡張 |
| 節の導入文 | `:::{.section-lead}` | 拡張 |
| コラム | `:::{.column}` | 拡張 |
| メモ・覚書き | `:::{.memo}` | 拡張 |
| ヒント・コツ | `:::{.tip}` | 拡張 |
| 補足説明 | `:::{.note}` | 拡張 |
| 重要な注意 | `:::{.notice}` | 拡張 |
| 補足を小さめに組む | `:::{.small}`（1 段落なら段落末に `{.small}`） | 拡張 |
| 出典・参考資料を小さめに組む | `:::{.references}`（1 段落なら段落末に `{.references}`） | 拡張 |
| 書籍紹介カード | `:::{.book-card}` | 図版 |
| 会話・対話を組む | `:::{.talk}` の中に「キー: 発話」を並べる | 拡張 |
:::

### レイアウト・余白

:::{.long-table}
| やりたいこと | 書き方 | 解説章 |
|:---|:---|:---|
| ブロックごと寄せる | `:::{.align-left}` / `.align-center` / `.align-right` | 拡張 |
| 文字の揃えだけ変える | 段落末尾に `{.text-right}` など（`.text-left` / `.text-center` も） | 拡張 |
| 二段組にする | `:::{.text-2dan}` | 拡張 |
| 段落の下に余白を空ける | 段落末尾に `{.aki}`（1 行分）/ `{.aki2}`（2 行分） | 拡張 |
| 余白を微調整する | `@vspace:1.5lh`（負の値で詰める。単位は `lh` `mm` など） | 拡張 |
| 行の頭を下げる | `@hspace:2`（単位省略時は em＝全角文字数） | 拡張 |
| 改ページする | `---` または `@pagebreak` | 拡張 |
| 右ページから始める | `@pagebreak:recto`（左ページなら `:verso`） | 拡張 |
| クラスを組み合わせる | `:::{.column .align-center}` のように併記 | 拡張 |
| 独自の装飾を作る | `:::{.myclass}` ＋ `stylesheets/custom.css` に定義 | 拡張 |
:::

### 参照・索引・データ

:::{.long-table}
| やりたいこと | 書き方 | 解説章 |
|:---|:---|:---|
| 図・表・コードを参照する | 定義側 `** タイトル @ラベル **`、参照側 `@ラベル` | 相互参照 |
| 見出しを参照する | 定義側 `## タイトル @ラベル`、参照側 `@ラベル` | 相互参照 |
| 章を参照する | `@chapref:ch-スラッグ`（章題だけなら `@ch-スラッグ`。ラベルはファイル名から自動で付く） | 相互参照 |
| ページ番号を添えて参照する | `@pageref:ラベル`（PDF のみ「（p.200）」が付く） | 相互参照 |
| 書名・版数・日付を差し込む | `@title` / `@version` / `@today` | 拡張 |
| QR コードを載せる | `@qr:https://example.com/`（既定 18mm 角。大きさは `{width=25mm}` を続ける） | 拡張 |
| 索引・用語集に登録する | `[用語\|読み]`（読みは省略可） | 索引 |
| 索引候補を自動抽出する | `vs index:auto` → レビュー → `vs index:apply` | 索引 |
| データを展開する | `= books \| tags=ruby \| 3`（`data/` の YAML＋テンプレート） | データ展開 |
:::

:::{.memo}
使いたい記法が見つかったら、表の書き方を原稿へ写して試せます。fancy list の空白規則や表の結合など、細かな決まりは各解説章を参照してください。
:::
