# この本について

　この本は、Vivlio Starter で縦書きの小説を組むための見本です。本文には、青空文庫の宮沢賢治「注文の多い料理店」を収めました。文庫判の紙面に、ルビ・会話文・挿絵がどのように組まれるかを確かめられます。

　巻末の付録「記法の見本」には、小説で使う書き方を並べました。ルビ・傍点・縦中横・挿絵・脚注の書き方と、小説投稿サイトの書き方の読み方を載せています。

　自分の作品を書くときは、`contents/` の原稿を書き換え、`config/catalog.yml` に章を並べます。書名と著者名は `config/book.yml` に書きます。`vs build` で PDF を組み、`vs lint` で原稿の書き方を確かめます。
