# 数式記法早見表

数式は `$…$`（インライン数式）と `$$…$$`（ディスプレイ数式）で囲んで書きます。中身は **LaTeX の記法でも、見たままの素の表記でも構いません**。どちらで書いても同じ結果になります。

書き方の基本と、バッククォートで囲んだ数式の扱いは「執筆チュートリアル」と「便利な拡張記法」で解説しました。ここでは**逆引きの早見表**として、書きたい形から記法を引けるようにまとめます。

## 基本の構造

| 書きたいもの | 素のまま書く | LaTeX で書く | 結果 |
| :--- | :--- | :--- | :--- |
| 上付き | ``x²`` ``10⁻³⁴`` | ``x^2`` ``10^{-34}`` | $x^2$　$10^{-34}$ |
| 下付き | ``H₂O`` ``aₙ`` | ``H_2O`` ``a_n`` | $H_2O$　$a_n$ |
| 冪乗（2 文字以上） | ``2^(1/3)`` ``a^(p-1)`` | ``2^{1/3}`` ``a^{p-1}`` | $2^{1/3}$　$a^{p-1}$ |
| 根号 | ``√2`` ``√(x+1)`` | ``\sqrt{2}`` ``\sqrt{x+1}`` | $\sqrt{2}$　$\sqrt{x+1}$ |
| 分数 | ``(a+b)/2`` | ``\frac{a+b}{2}`` | $\frac{a+b}{2}$ |
| 総和 | ``Σ(i=1 to n)`` | ``\sum_{i=1}^{n}`` | $\sum_{i=1}^{n}$ |
| 積分 | ``∫[0, 1]`` | ``\int_{0}^{1}`` | $\int_{0}^{1}$ |
| 極限 | ``lim(n→∞)`` | ``\lim_{n \to \infty}`` | $\lim_{n \to \infty}$ |
| 剰余 | ``a mod n`` | ``a \bmod n`` | $a \bmod n$ |

:::{.note}
根号は**直後のひとかたまり**に掛かります。``√x+1`` は「√x に 1 を足す」という意味になるので、全体に掛けたいときは ``√(x+1)`` と括弧で括ってください。分数も同じで、``\frac{a+b}{2}`` のように**どこまでが分子か**を明示します。
:::

## ギリシャ文字

**そのまま入力して構いません。** 日本語入力の変換（「あるふぁ」→ α）や記号パレットから直接打てます。LaTeX のコマンドで書いても結果は同じです。

| :--- | :--- | :--- | :--- | :--- |
| アルファ | α | ``\alpha`` | Α | （なし） |
| ベータ | β | ``\beta`` | Β | （なし） |
| ガンマ | γ | ``\gamma`` | Γ | ``\Gamma`` |
| デルタ | δ | ``\delta`` | Δ | ``\Delta`` |
| イプシロン | ε | ``\epsilon`` | Ε | （なし） |
| ゼータ | ζ | ``\zeta`` | Ζ | （なし） |
| イータ | η | ``\eta`` | Η | （なし） |
| シータ | θ | ``\theta`` | Θ | ``\Theta`` |
| イオタ | ι | ``\iota`` | Ι | （なし） |
| カッパ | κ | ``\kappa`` | Κ | （なし） |
| ラムダ | λ | ``\lambda`` | Λ | ``\Lambda`` |
| ミュー | μ | ``\mu`` | Μ | （なし） |
| ニュー | ν | ``\nu`` | Ν | （なし） |
| クサイ | ξ | ``\xi`` | Ξ | ``\Xi`` |
| オミクロン | ο | ``\omicron`` | Ο | （なし） |
| パイ | π | ``\pi`` | Π | ``\Pi`` |
| ロー | ρ | ``\rho`` | Ρ | （なし） |

| タウ | τ | ``\tau`` | Τ | （なし） |

| カイ | χ | ``\chi`` | Χ | （なし） |
| プサイ | ψ | ``\psi`` | Ψ | ``\Psi`` |
| オメガ | ω | ``\omega`` | Ω | ``\Omega`` |

:::{.note}
**大文字の「（なし）」は、LaTeX にコマンドがないという意味です。** ラテン文字の大文字と同じ形なので、TeX は専用のコマンドを用意していません。``\Alpha`` と書いてもそのまま文字列として出てしまいます。

**ギリシャ文字はそのまま入力すれば正しく組まれます。** 大文字はそちらをお使いください。

字体の違う異体字も使えます。ϵ ``\varepsilon``・ϑ ``\vartheta``・ϖ ``\varpi``・ϱ ``\varrho``・ς ``\varsigma``・ϕ ``\varphi`` です。
:::

## 記号

こちらも**そのまま入力できます**。左が実際の字、右が LaTeX のコマンドです。

| 分類 | 記号と LaTeX のコマンド |
| :--- | :--- |
| 四則・演算 | + ``+``　- ``-``　× ``\times``　÷ ``\div``　⋅ ``\cdot``　± ``\pm``　∓ ``\mp``　∘ ``\circ`` |
| 等号・不等号 | = ``=``　≠ ``\neq``　< ``<``　> ``>``　≤ ``\leq``　≥ ``\geq``　≪ ``\ll``　≫ ``\gg`` |
| 近似・比例 | ≈ ``\approx``　≡ ``\equiv``　∼ ``\sim``　∝ ``\propto`` |
| 集合 | ∈ ``\in``　∉ ``\notin``　⊂ ``\subset``　⊃ ``\supset``　∪ ``\cup``　∩ ``\cap``　∅ ``\emptyset`` |
| 論理・限量 | ∀ ``\forall``　∃ ``\exists``　⊥ ``\perp``　∞ ``\infty`` |
| 矢印 | → ``\to``　← ``\leftarrow``　↦ ``\mapsto``　⇒ ``\Rightarrow``　⇐ ``\Leftarrow``　⇔ ``\Leftrightarrow`` |
| 大型演算子 | ∑ ``\sum``　∏ ``\prod``　∫ ``\int``　∮ ``\oint`` |
| 微分・その他 | ∂ ``\partial``　∇ ``\nabla``　⟨ ``\langle``　⟩ ``\rangle``　… ``\ldots`` |

:::{.note}
`=` `<` `>` `+` `-` は**そのまま打てば通ります**。専用のコマンドはありません（記号そのものが使えます）。全角で ＝ ＋ − と書いても、半角へ直したうえで組みます。
:::

## 関数

関数名は**そのまま書いて構いません**。LaTeX ではコマンドとして書きます。

```markdown
$sin²θ + cos²θ = 1$                 素のまま
$\sin^2\theta + \cos^2\theta = 1$   LaTeX
```

表示結果は次のようになります。{.aki}

$\sin^2\theta + \cos^2\theta = 1${.aki}

使えるのは次の 38 種です。どれも**素のままでも LaTeX でも書けます**。{.aki}

| 分類 | 関数名 |
| :--- | :--- |
| 三角関数 | ``sin`` ``cos`` ``tan`` ``sec`` ``csc`` ``cot`` |
| 逆三角関数 | ``arcsin`` ``arccos`` ``arctan`` |
| 双曲線関数 | ``sinh`` ``cosh`` ``tanh`` ``coth`` |
| 指数・対数 | ``exp`` ``log`` ``ln`` ``lg`` |
| 極限 | ``lim`` ``liminf`` ``limsup`` ``injlim`` ``projlim`` ``varliminf`` ``varlimsup`` ``varinjlim`` ``varprojlim`` |
| 最大・最小・上限・下限 | ``max`` ``min`` ``sup`` ``inf`` |
| 代数・幾何 | ``det`` ``dim`` ``deg`` ``ker`` ``hom`` ``gcd`` ``arg`` |
| 確率 | ``Pr`` |

:::{.note}
一覧にない関数名は、`\operatorname{…}` で囲んでください。たとえば行列の階数 `rank`（行列に含まれる 1 次独立な行・列の最大数）は一覧にありません。``\operatorname{rank}(A)`` と書けば `rank` がひとまとまりの関数名として組まれます。囲まないと 1 文字ずつ別々の変数として扱われ、`r × a × n × k` の積のように読めてしまいます。
:::

## ディスプレイ数式にするもの

総和・積分・極限・大きな分数は、**ディスプレイ数式（`$$…$$`）で書いてください**。インラインに置くと、TeX の決まりで上下限が記号の横へ寄り、高さも圧縮されて読みにくくなります。

```markdown
$$\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$$

$$\lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = e$$
```

表示結果は次のようになります。{.aki}

$$\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$$

$$\lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = e$$

複数行を揃えたいときは、言語に `math` と書いたコードブロックの中へ 1 行ずつ書きます。**各行を `$$` で囲む必要はありません**。`=` や `≈` の位置で自動的に揃います（GitHub と同じ書き方です）。

````markdown
```math
cos θ = 1 - θ²/2! + θ⁴/4! - θ⁶/6! + ...
sin θ = θ - θ³/3! + θ⁵/5! - θ⁷/7! + ...
```
````

表示結果は次のようになります。{.aki}

```math
cos θ = 1 - θ²/2! + θ⁴/4! - θ⁶/6! + ...
sin θ = θ - θ³/3! + θ⁵/5! - θ⁷/7! + ...
```

言語を書かないコードブロックでも、中身が数式だと判定できれば同じように組まれます。判定の詳しい話は「便利な拡張記法」を参照してください。

## Kindle での見え方

Kindle では、画像を本文のフォントサイズへ追従させる手段がありません。そこで**インライン数式は本文テキストへ変換**して埋め込みます。読者が文字を大きくすれば、数式も一緒に大きくなります。

- 上の表にある記法は、ほぼすべてテキストになる（``√2``・``∑`` と上下限・``(a+b)/2`` など）
- テキストで表しようがない式（2 段重ねの上付き ``x^{y^z}``、入れ子の分数など）だけが画像のまま残る。同じ式を素の表記で書けば、書いたとおりの文字で表示され、追従する
- **ディスプレイ数式は画像のまま**。総和や積分の組版を保つためで、行を占有するので崩れない
