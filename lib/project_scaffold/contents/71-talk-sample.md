## はじめての「こんにちは」

放課後の図書室。未來くんがノートパソコンを抱えてやってきました。

:::{.talk}
mirai: 遙香お姉さま、プログラミングを教えてください！
haruka: あら、どうしたの急に。……その「お姉さま」はやめてちょうだい、くすぐったいわ。
mirai: じゃあ、遙香お姉さん。
haruka: まあいいわ。じゃあ **Ruby** から始めましょうか。
        日本で生まれた言語で、書いていて楽しいことを何より大事にしているの。
:::

まずは画面に文字を出すところから始めます。

```ruby
puts "こんにちは、Ruby!"
```

:::{.talk}
mirai: `puts` って、なんて読むんですか？
haruka: 「プット・エス」と読む人が多いわね。**put string**、つまり「文字を置く」という意味よ。
mirai: これだけで動くんですか？
haruka: ええ。ファイルに保存して `ruby hello.rb` と打てば、それで動くわ。
        おまじないみたいな決まり文句を先に書く必要はないの。
mirai: すごい！　思ってたより、ずっと短いです。
:::

## 変数 — 名前を付ける

:::{.talk}
haruka: 次は**変数**ね。値に名前を付けて、あとから何度でも呼び出せるようにする仕組みよ。
mirai: 数学で習った `x = 3` みたいなものですか？
haruka: 考え方は近いわ。ただプログラミングの `=` は「等しい」ではなくて、
        「右のものを左の名前に入れる」という意味なの。ここは大事なところよ。
:::

```ruby
name = "未來"
puts "こんにちは、#{name}さん!"
```

:::{.talk}
mirai: 文字列の中に `#{name}` って書いてありますね。
haruka: それが**式展開**。二重引用符の中で `#{ }` を書くと、その中身が値に置き換わるの。
mirai: なるほど、名前を変えるだけで挨拶が変わるんですね。
haruka: そう。同じことを何度も書かずに済むでしょう。
        プログラミングの上達は「同じことを二度書かない工夫」を覚えることでもあるのよ。
:::

## 数を計算してみる

:::{.talk}
haruka: 計算もそのまま書けるわ。ちょっと意地悪な例を出してみましょうか。
:::

```ruby
puts 3 + 4       # => 7
puts 10 / 3      # => 3
puts 10.0 / 3    # => 3.3333333333333335
```

:::{.talk}
mirai: あれ、`10 / 3` が **3** になっています。3.33 じゃないんですか？
haruka: いいところに気づいたわね。整数どうしの割り算は、答えも整数になるの。
        小数がほしいときは、`10.0` のようにどちらかを小数にしておくのよ。
mirai: 気をつけないと、いつのまにか答えがずれてしまいそうです。
haruka: そうやって「なぜ？」と立ち止まれるなら、きっと伸びるわ。
:::

## 繰り返し — `each`

:::{.talk}
haruka: 同じ処理を何度も繰り返したいときは `each` を使うわ。
        Ruby ではこれが一番よく使う繰り返しかもしれないわね。
:::

```ruby
fruits = ["りんご", "みかん", "ぶどう"]

fruits.each do |fruit|
  puts "#{fruit} が好きです"
end
```

:::{.talk}
mirai: `do` から `end` までが、繰り返される部分ですか？
haruka: そのとおり。`|fruit|` のところに、ひとつずつ順番に入ってくるの。
mirai: 三行が三回ぶん、勝手に実行されるんですね。……ちょっと感動しました。
haruka: ふふ、その感じは大切にしてね。
        「機械が代わりに働いてくれる」という手触りが、プログラミングの入り口だから。
:::

## メソッドを作る

:::{.talk}
haruka: 最後にもうひとつ。まとまった手順に名前を付けたものを**メソッド**というの。
mirai: さっきの `puts` も、そのメソッドなんですか？
haruka: ええ、`puts` は最初から用意されているメソッドね。自分で作ることもできるのよ。
:::

```ruby
def greet(name)
  "こんにちは、#{name}さん!"
end

puts greet("遙香")
puts greet("未來")
```

:::{.talk}
mirai: `return` を書いていないのに、答えが返っているみたいです。
haruka: Ruby は最後に評価した値がそのまま戻り値になるの。だから `return` は省略できるわ。
mirai: 短く書けるように、あちこち工夫されているんですね。
haruka: そう。**書く人の気持ちよさ**を大事にしている、というのがよく分かる例ね。
:::
