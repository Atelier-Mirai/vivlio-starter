# 相互参照（クロスリファレンス）

:::{.chapter-lead}
図や表を増やし、章の順番を入れ替えていくと、原稿に直接書いた「図 3-2」のような番号は変わってしまいます。相互参照（クロスリファレンス）を使えば、原稿では図・表・コードへ変わらない名前を付け、読者に見せる番号はビルド時に決められます。本章では、図表への番号の付け方から、見出し・章の参照、ページ番号を添える方法までを説明します。
:::

## 図・表・コードに番号を付ける

相互参照は、参照される要素に名前（ラベル ID）を付ける「定義」と、その名前を本文から呼ぶ「参照」の二つで使います。

1. **定義**: 図・表・コードの直前の行に、キャプションと `@ラベルID` を書く
2. **参照**: 本文に `@ラベルID` と書く

ビルド時には、図・表・リスト（コード）のそれぞれに「章番号-連番」の番号が振られ、本文の `@ラベルID` は「図 3-2」「表 4-1」「リスト 5-3」のような番号へのリンクに置き換わります。図表を追加したり章を並べ替えたりしても、次のビルドで番号と参照が追随します。ラベルは本書全体から探すので、別の章の図表も同じ書き方で参照できます。

番号の種類は、キャプションの直後が画像なら図、表なら表、コードブロックならリストと決まります。ラベル ID に `fig-` のような接頭辞を付ける必要はありません。

### 図

画像の直前の行に、図の見出しとなるキャプション「アインシュタインの写真」を `**` で囲んで書き、その末尾に半角空白を空けて `@einstein` を付けます。この `einstein` が、図のラベル ID です。キャプションと画像の間は、空行を入れても構いません。

```markdown
** アインシュタインの写真 @einstein **
![](Einstein.png){width=40% align=center}
```

:::{.output}
** アインシュタインの写真 @einstein **
![](Einstein.png){width=40% align=center}
:::

キャプションには「図 1-1:」のような図番号が付き、`@einstein` は表示されません。本文に `@einstein` と書くと、この図番号へのリンクになります。

::::{.side-by-side}
```markdown
@einstein は、研究するアインシュタインのイメージ画像です。
```

:::{.output}
@einstein は、研究するアインシュタインのイメージ画像です。
:::
::::

画像の大きさや配置の指定は @chapref:ch-figures で説明しています。

### 表

表も同じく、キャプション「基本的な表」の末尾に `@basic-table` を付けます。

::::{.side-by-side}
```markdown
** 基本的な表 @basic-table **
| 名前 | 年齢 | 職種         |
| :--: | :--: | :----------: |
| 太郎 |  25  | エンジニア   |
| 花子 |  30  | デザイナー   |

@basic-table は、表の一例です。
```

:::{.output}
** 基本的な表 @basic-table **
| 名前 | 年齢 | 職種         |
| :--: | :--: | :----------: |
| 太郎 |  25  | エンジニア   |
| 花子 |  30  | デザイナー   |

@basic-table は、表の一例です。
:::
::::

### コード（リスト）

コードも同じく、キャプション「Ruby のサンプル」の末尾に `@ruby-sample` を付けます。

::::{.side-by-side}
````markdown
** Ruby のサンプル @ruby-sample **
```ruby
def hello(name)
  puts "Hello, #{name}!"
end
```
````

** Ruby のサンプル @ruby-sample **
```ruby
def hello(name)
  puts "Hello, #{name}!"
end
```
::::

本文の `@ruby-sample` は @ruby-sample になります。

外部ファイルから取り込んだコード（@chapref:ch-extensions）にも、同じようにキャプションを付けられます。

````markdown
** 素数を列挙する @prime-range **
```include:prime.rb:14-17```
````

と書くと、次のように表示されます。

** 素数を列挙する @prime-range **
```include:prime.rb:14-17```

本文の `@prime-range` は @prime-range になります。

### 番号だけを付ける・番号を付けない

本文から参照しない図表には、ラベル ID の代わりに `@auto` を書くと、番号だけが付きます。名前を付けたラベルは、どこからも参照しないと 🟡 で警告されます（@pageref:label-warnings）。`@auto` の図表は警告されません。

::::{.side-by-side}
````markdown
** 挨拶を表示する @auto **
```ruby
puts "Hello!"
```
````

** 挨拶を表示する @auto **
```ruby
puts "Hello!"
```
::::

`@` を書かなければ、番号の付かないキャプションになります。本文から指し示す必要のない短い例まで、すべてに番号を付ける必要はありません。

::::{.side-by-side}
````markdown
** CSS の例 **
```css
h1 { color: red; }
```
````

** CSS の例 **
```css
h1 { color: red; }
```
::::

## 見出し・章を参照する

見出しと章は、番号ではなく題で参照します。ラベルの付け方は見出しと章で違いますが、参照の書き方は共通です。

### ラベルを付ける

見出しには、行末に半角空白と `@ラベルID` を書いてラベルを付けます。行末の `@ラベルID` は紙面・目次・柱には表示されません。たとえば、この章の「ラベル ID の決まり」の節は、原稿では次のように書いています。

```markdown
## ラベル ID の決まり @id-rules
```

章には、ラベルを書かなくてもファイル名からラベルが付きます。ファイル名の番号を除いた部分（スラッグ）の前に `ch-` を付けたものが、その章のラベルです。

| ファイル | ラベル |
| :--- | :--- |
| `44-build.md` | `@ch-build` |
| `90-notation-cheatsheet.md` | `@ch-notation-cheatsheet` |

### 参照の書き方

参照は三通りに書けます。`@ラベルID` は題を鉤括弧で括って表示し、`@pageref:` はページ番号を、`@chapref:` は章番号とページ番号を添えます。`@chapref:` に指定できるのは章のラベルだけです。

::::{.side-by-side}
```markdown
@id-rules の節
@pageref:id-rules の節
@ch-build の章
@chapref:ch-build を参照
```

:::{.output}
@id-rules の節
@pageref:id-rules の節
@ch-build の章
@chapref:ch-build を参照
:::
::::

読者が参照先を探す手間に応じて、次のように使い分けます。

- 同じ見開きにある見出しや「前の章」「次の章」のように、めくれば見つかるときは `@ラベルID`
- 離れた見出しを指すときや、章題を文に組み込むときは `@pageref:`
- 「〜を参照してください」のように、章そのものへ案内するときは `@chapref:`

ページ番号は組版した結果から決まるので、原稿の増減で参照先のページが変わっても追随します。EPUB と Kindle は文字の大きさや画面によってページの区切りが変わるため、ページ番号を付けずに表示します。章番号は章扉と同じ形で、付録なら「付録 A」となり、前書き・後書きには付きません。`@pageref:` は図表のラベルにも使えます（`@pageref:einstein` → @pageref:einstein）。

同じ段落で同じラベルを二度 `@pageref:` や `@chapref:` で参照すると、二度目以降はページ番号を省きます。段落の組み立てを気にせず、離れた箇所を参照するときは毎回 `@pageref:` や `@chapref:` と書いて構いません。

鉤括弧で表示する参照は、和文と接する側の半角空白を紙面に出しません。原稿では、参照の前後に半角空白を置いて区切って書けます。

:::{.note}
**章ラベルの注意**

- `前の章 @ch-new` のように隣の章を指す参照は、`catalog.yml` の章の並びと合わなければ、正しい章のラベルを添えて 🟡 で警告します。
- `vs rename 12-new 12-project` のようにスラッグを変えると、本文の `@ch-new` も新しいラベルに書き換わります。
- スラッグのない章（`11.md`）には、ラベルが付きません。
:::

## ラベル ID の決まり @id-rules

ラベル ID の付け方は、プログラムやファイル名で名前を付けるときの一般的な決まりと同じです。半角の英字（a〜z・A〜Z）・数字（0〜9）・ハイフン（`-`）・アンダースコア（`_`）だけで書き、日本語・空白・そのほかの記号は使えません。使えない文字を含む ID（`@図の例`）はラベルにならず、🟡 で警告されます。書籍全体で、英小文字・数字・ハイフンでつなぐ形（`@ruby-sample`・`@basic-table`）に揃えると、ID から参照先を推測しやすくなります。ID は対象の内容から名付けます。図表の順番や章番号を含めると、並べ替えたときに食い違います。

次の名前は、ラベル ID に使えません。`auto`・`id` は番号だけを付ける指定になり、それ以外はビルド時に 🔴 で報告されます。

- `auto`・`id`（`@id` は `@auto` と同じ）
- `ch-` で始まる名前（章のラベル）
- `vspace`・`hspace`・`pagebreak`・`pageref`・`chapref`・`version`・`title`・`today`・`qr`（ビルド時に置き換わる記法。@chapref:ch-extensions）

### 一意性

ラベル ID は、図・表・リスト・見出しをまたいで、本書全体で一意でなければなりません。同じ ID を二箇所以上で定義すると、定義した行番号を添えて、ビルド時に 🔴 で報告されます。

:::{.output}
```text
🔴 12-data.md:42 - ラベルID '写真 @photo' は重複しています
        重複箇所: 12-data.md: 42, 88
        → どちらかの ID を、対象を区別できる別の名前に変えてください。
```
:::

報告されてもビルドは最後まで進みますが、後の定義にも先の定義と同じ番号が付き、参照はすべて先の定義を指します。

### 参照の警告 @label-warnings

参照の誤りは 🟡 で警告されます。重複・未定義・孤立は、`vs preflight` でビルドの前に確かめられます（@chapref:ch-utility）。

- **未定義のラベル**: 参照先が見つからない `@ラベルID` は、紙面に文字のまま残ります。綴りの近いラベルがあれば「もしかして」として添えます
- **孤立ラベル**: 定義したのに、どこからも参照されていないラベル
- **参照先のない `@pageref`**: `@pageref:id-rules` のように、`:` に続けて ID を書きます

:::{.output}
```text
🟡 25-cross-reference.md:9 - 未定義のラベルID: @id-rule（もしかして: @id-rules）
```
:::
