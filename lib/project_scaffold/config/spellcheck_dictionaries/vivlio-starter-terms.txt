# vivlio-starter 自身の機能・記法・コマンド名・設定キーのうち、cspell 由来の
# 標準辞書に未収録のものを補う、プロジェクト管理の辞書（フォークの原稿でも使う語）。
# 大文字小文字は無視されるため（word_map は downcase キー）、小文字 1 形で十分。
#
# どの技術書でも出てくるツール名・略語・人名は、内容の合う辞書に置く
# （製品・ツール・規格は products.txt、略語は abbreviations.txt、人名は famous-people.txt）。
# 本固有の作例（サンプル画像のローマ字名・作例の識別子など）は config/spellcheck_user_dictionary.yml へ。
