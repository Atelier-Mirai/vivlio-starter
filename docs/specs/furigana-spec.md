## 0. 決定の一覧（骨格）

| 項目 | 決定 |
| :--- | :--- |
| 形 | `vs index:auto` → `index:apply` と同じ 2 段にする。`vs furigana:auto [章]` が候補を調べてレビューのファイルを書き、著者が直して、`vs furigana:apply` が原稿に書き込む。ビルドの段にはしない |
| 基準の水準 | `book.yml` のキー `furigana.level`（対象の読者は本の性質で、著者が答えを持つ）。値は `grade1`〜`grade6`（その学年より上の漢字に振る）・`junior`（中学以上で習う字に振る）・`non_joyo`（常用漢字の外だけ）。対応は `furigana-level-spec.md` §3.1。既定値は置かず、無ければ `vs furigana:auto` が 🔴 で書き方を示す。引数 `--level` で 1 回だけ変えられる |
| 振る範囲 | キー `furigana.repeat`。`chapter`（章ごとの初出だけ）・`all`（全部）。`BookProfile` で `novel` は `chapter`、`picture_book` は `all` にする。ページごとの初出は、原稿の時点ではページが分からないので作らない |
| 単位 | 語（形態素）。対象の水準の字を 1 つでも含む語の全体に振る。送り仮名は外に出す（`{食|た}べる`）。字ごとに分けない（連濁と熟字訓で誤るため） |
| 読みの出どころ | 著者の辞書（`config/furigana.yml`。語 → 読み、と「振らない語」）→ 補助辞書（交ぜ書き辞書から起こす `MazegakiDictionary.readings`）→ MeCab、の順 |
| 自動で振らないもの | 未知語・読みの候補が複数ある語・補助辞書と MeCab で読みが違う語・人名と地名（MeCab の品詞が固有名詞）。レビューのファイルに「読みを書いてください」として場所つきで並べる |
| 安全 | 既にルビのある箇所・コード・URL・数式には触れない。`apply` は置き換える行を全部見せてから確認し、`.vs-backup/furigana/` へ退避する。2 回走らせても増えない |
| 投稿サイトの記法との関係 | 書き込むのは vs の記法 `{漢字|よみ}`。`notation.web_novel` の本で投稿サイトの記法で書き込むかは、この仕様書で決める（判断の軸: 同じ原稿を投稿サイトへ出す著者が、ルビを二つの書き方で持たずに済むか） |

- キーの名前（`furigana.level`・`furigana.repeat`）・値・コマンドの名前は著者から見える名前で、S8c で確定したら了承待ちの一覧に載せる（`v2-migration-plan.md` §4.1）。
- 補助辞書の種（交ぜ書き辞書から取れる表外漢字の読み 125 字）と、MeCab が稀な漢字ほど誤読する理由は、`PLANNED.md` の項にある。
