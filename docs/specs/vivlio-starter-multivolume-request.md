# Vivlio Starter 分冊対応の改善要求

『AIと学ぶモダンWebサイト入門』を上下巻に分けて組んだときに見えた課題と、分冊に対応させるために欲しい機能をまとめます（2026-10-17）。実装の方法や可否は、別に調べます。

## 1. 今回の分け方と、起きたこと

### 1.1 分け方

- `config/catalog-upper.yml`（上巻）と `config/catalog-lower.yml`（下巻）を作り、組むたびに `config/catalog.yml` へ写して `vs build` した。
- 上巻：前書き（00）、第 1〜3 部（01〜12 章）、付録 90〜93。
- 下巻：第 4〜6 部（21〜30 章）、付録 90〜93（上巻と同じもの）、後書き（99）。

### 1.2 起きたこと

| 起きたこと | 困ること |
| :--- | :--- |
| 下巻の章番号が「第1章」から始まる | 上巻から続けて「第13章」にできない。前書きや本文で書いた章番号と食い違う |
| 下巻の付録が「付録A」から始まる | 今回は共通の付録なので困らないが、巻ごとに付録が違う本では「付録E」から続けられない |
| 別の巻の章を指す `@chapref` が「未定義のラベルID」になる | 上巻で 2 件、下巻で 19 件。手で「上巻の第8章「…」」と書き換えるしかない |
| 用語集の語が「ビルド対象章に出現しません」と大量に警告される | 別の巻にだけ出る語も警告されるので、本当に消えた語を見つけにくい |
| 出力ファイル名が巻によらず同じ（`book_ai_web_starter_v0.1.0.pdf`） | 続けて組むと前の巻の PDF を上書きする。手で名前を変えて退避する必要がある |
| 目次を切り替えるために `catalog.yml` を書き換える | 戻し忘れると、次の `vs create` や `vs preflight` が片方の巻だけを対象にする |
| 前書きは `00`、後書きは `99` の一つずつ | 巻ごとの前書き（「下巻の始めに」など）を置く方法がない |
| 目次はその巻の分だけ | 全巻の構成を示す目次を載せられない |

## 2. 改善要求

優先度は、**必須**（これがないと分冊を組めない、または手作業が多い）、**推奨**（あると仕上がりがよくなる）、**任意**（将来あるとよい）の三つで示します。

### 2.1 巻を定義する（必須）

- `catalog.yml` に巻を書けるようにする。巻の数は自由（上下、上中下、第一分冊・第二分冊…）。
- 巻ごとに、呼び名（「上巻」「第一分冊」など）と、ファイル名に使う短い名前（`vol1` など）を付けられる。
- 巻を書かない `catalog.yml` は、今までどおり一冊として組む（互換性を保つ）。
- 同じ原稿（共通の付録など）を、複数の巻に載せられる。

書き方の案：

```yaml
# config/catalog.yml
VOLUMES:
  - name: 上巻
    id: vol1
    PREFACE:
      - 00-preface
    CHAPTERS:
      - コンピュータとAI、Webへの入り口:
          - 01-computer
          - 02-ai
    APPENDICES:
      - 90-how-to-ask
      - 93-cheatsheet

  - name: 下巻
    id: vol2
    PREFACE:
      - 20-volume2-intro     # 巻ごとの前書き（2.5 を参照）
    CHAPTERS:
      - じゃんけんアプリを育てる:
          - 21-janken-simple
    APPENDICES:
      - 90-how-to-ask        # 上巻と共通
      - 93-cheatsheet
    POSTFACE:
      - 99-postface
```

### 2.2 巻を選んで組む（必須）

- `vs build --volume vol2`（または `vs build 下巻`）のように、巻を選んで組める。
- `vs build --all-volumes` で、全巻を続けて組める。
- 出力ファイル名に巻の名前が入る（例：`book_ai_web_starter_vol2_v0.1.0.pdf`）。名前の形は `book.yml` で決められる。
- 巻をまたいで一冊にまとめた版（合本）も組める（校正用、電子版用）。
- `vs preflight`・`vs lint`・`vs metrics` も、巻を選んで動く。`vs metrics` は巻ごとの合計（文字数・ページの目安）を出す。

### 2.3 章・部の番号の付け方を選ぶ（必須）

- 章番号を、全巻で通す（下巻は第13章から）か、巻ごとに 1 から始めるかを選べる。
- 巻ごとに、始まりの章番号を直接指定することもできる。
- 部の番号（第 4 部など）も同じように、通すか巻ごとかを選べる。
- 図・表・リストの番号（図 13-2 など）は、章番号に合わせて変わる。

```yaml
# config/book.yml（案）
volumes:
  numbering:
    chapters: continuous   # continuous … 全巻で通す / restart … 巻ごとに 1 から
    parts: continuous
```

### 2.4 付録の記号の付け方を選ぶ（必須）

- 付録の記号を、巻ごとに A から始めるか、前の巻から続けるか（下巻は付録E から）を選べる。
- 共通の付録は、どの巻でも同じ記号にできる（上巻でも下巻でも「付録A うまく伝えるための言い方集」）。
- 巻ごとに、始まりの記号を直接指定することもできる。

```yaml
volumes:
  numbering:
    appendices: shared     # shared … 共通の付録は同じ記号 / continuous … 前の巻から続ける / restart … 巻ごとに A から
```

### 2.5 巻ごとの前書き・後書きを置く（必須）

- 前書き・後書きを、巻ごとに置ける。今の「`00` が前書き、`99` が後書き」という番号の決まりに縛られず、`catalog.yml` の `PREFACE`・`POSTFACE` に書いた原稿をその巻の前書き・後書きとして扱う。
- 全体の前書きは第 1 巻だけ、全体の後書きは最終巻だけ、という置き方もできる。
- 2 巻目以降の前書き用の雛形（前の巻の要約、サンプルコードの入手先、作業フォルダなど）を `templates/` に用意する。

### 2.6 巻をまたぐ参照（必須）

- `@chapref`・`@pageref`・`@ch-` が、別の巻の章を指せる。表示は巻の名前を添えた形にする。
  - 例：`@chapref:ch-dom` → 上巻 第8章「JavaScript でページを操作する」
- 別の巻の参照には、ページ番号を付けない（付けるかどうかを選べてもよい）。PDF・EPUB では、別の巻へのリンクにしない。
- 図・表・見出しのラベル（`@fig-…` など）も、別の巻を指せる。
- 表示の形（「上巻 第8章」「第一分冊 第8章」など）を `book.yml` で決められる。
- `vs preflight` は、どの巻にもないラベルだけを「未定義」として知らせる。別の巻にあるラベルは、正しい参照として扱う。
- 「前の章」「次の章」の検査は、巻の境目を考える（下巻の最初の章の「前の章」は、上巻の最後の章）。

### 2.7 目次（推奨）

- その巻の詳しい目次（今の目次）に加えて、全巻の構成を示す目次を載せられる。
- 全巻の目次の細かさを、章まで・節までから選べる。
- 全巻の目次では、今の巻を目立たせ、ほかの巻の章には巻の名前を添える。

```yaml
volumes:
  toc:
    whole: chapter         # none … 載せない / chapter … 章まで / section … 節まで
    position: before       # その巻の目次の前に置くか、後に置くか
```

### 2.8 書名・表紙・奥付（推奨）

- 巻ごとに、書名に添える巻名（「上巻」「第一分冊」）を設定できる。扉・表紙・背表紙・奥付・PDF のメタデータに反映する。
- 巻ごとに副題・表紙の絵・ISBN・発行日・版を設定できる。
- `vs cover` が、巻ごとに表紙・裏表紙を作れる。

### 2.9 索引・用語集（推奨）

- 索引と用語集を、巻ごとに作る。その巻に出てくる語だけを載せる。
- 「用語集語がビルド対象章に出現しません」の警告は、どの巻にも出てこない語だけに出す。
- 主要参照（「- 主要参照: 11, 12」）を、別の巻の章に向けられる（または、その巻にない主要参照は外して載せる）。
- 全巻を通した索引を、最終巻に載せる選び方もできる（任意）。

### 2.10 章の管理コマンド（推奨）

- `vs create`・`vs rename`・`vs delete` が、巻を書いた `catalog.yml` を正しく書き換える。`vs create 31-xxx --volume vol2` のように、巻を指定して章を足せる。
- `vs renumber` が、巻の区切りを保ったまま番号を振り直せる。

### 2.11 ページ番号（任意）

- ページ番号（ノンブル）を、巻ごとに 1 から始めるか、全巻で通すかを選べる（通常は巻ごと）。

## 3. 今の回り道（改良されるまで）

- 巻ごとの目次は `config/catalog-upper.yml`・`config/catalog-lower.yml` に置き、組むときに `config/catalog.yml` へ写す。組み終えたら全体の目次に戻す。
- 組んだ PDF は、次の巻を組む前に別の名前で退避する。
- 巻をまたぐ参照は、`@chapref` を使わず「上巻の第8章「JavaScript でページを操作する」」のように文で書く。
- 下巻の章番号は第1章から始まる（始まりの番号は変えられない）。上巻から下巻の章を文で指すときは、紙面に出る下巻での番号に合わせる。
