> 作成日: 2026-07-28
> ステータス: **仮**（L0〜L4 と学年判定は `vs metrics` で実装済み・`vs furigana` 本体は未着手）
> 対象: `PLANNED.md`「`vs furigana`（半自動ルビ付与）」が参照するレベル定義
> 関連: `lib/vivlio_starter/cli/metrics/kanji_levels.rb`（実装）, `lib/vivlio_starter/cli/metrics/data/kyoiku_joyo_kanji.tsv`（同梱データ）, `contents/32-metrics.md`「漢字レベル（ルビ候補）」（著者向け説明）

## 0. なぜこの仕様書があるか

`PLANNED.md` の `vs furigana` の項が「レベル定義は furigana-level-spec 参照＝`vs metrics` と共通の L0〜L4」と書いていたが、その仕様書は書かれていなかった（2026-07-28 に発覚）。

定義の実体は `kanji_levels.rb` の冒頭コメントにあり、`vs metrics` の「漢字レベル（ルビ候補）」として**既に実装・稼働している**。`vs furigana` は同じ定義を共有する前提なので、コード内コメントに埋まったままにせず、両コマンドが参照する 1 箇所へ引き出す。**新しい定義を決める仕様書ではなく、現状の定義を記録し、`vs furigana` を作るときに効いてくる論点を添えたもの**である。

## 1. レベル定義

| レベル | 表示ラベル | 内容 | 判定方法 |
| :--- | :--- | :--- | :--- |
| **L0** | 教育 | 小学校の学年別漢字配当表の漢字 | 同梱データ（学年 1〜6） |
| **L1** | 中学 | 中学で習う常用漢字 | 同梱データ（`中学`） |
| **L2** | 一般(L2) | JIS 第一水準 ∖ 常用漢字（人名・地名など） | 符号位置から算出 |
| **L3** | 専門(L3) | JIS 第二水準（専門的・旧字体） | 符号位置から算出 |
| **L4** | JIS外 | JIS X 0208 に無い漢字（第三水準・補助漢字など） | 変換不能 |

内部のシンボルは `:kyoiku` / `:chugaku` / `:ippan` / `:senmon` / `:gaiji`（`KanjiLevels::LABELS`・`ORDER`）。「L0〜L4」という番号は著者向けの通し番号で、コード上の識別子ではない。

判定は `KanjiLevels.level_of(char)` の 1 箇所に集約されている:

1. 同梱 TSV を引き、値が `中学` なら **L1**、それ以外の値（学年 1〜6）があれば **L0**
2. 表に無ければ EUC-JP へ変換し、第 1 バイトの区が 47 以下なら **L2**、超えれば **L3**
3. EUC-JP に変換できなければ **L4**

**JIS 水準の判定に符号位置を使うのは意図的**で、第一/第二水準の文字表を同梱しなくて済む（JIS X 0208 の区分がそのまま水準の境界になっている）。同梱データは常用漢字の内訳（L0/L1）にだけ必要。

## 2. 同梱データ

`lib/vivlio_starter/cli/metrics/data/kyoiku_joyo_kanji.tsv` — 各行「漢字 TAB レベル」。学年ごとにコードポイント昇順で並べる。

| 学年 | 字数 |
| :--- | ---: |
| 1 年 | 80 |
| 2 年 | 160 |
| 3 年 | 200 |
| 4 年 | 202 |
| 5 年 | 193 |
| 6 年 | 191 |
| **L0 小計** | **1026** |
| 中学（L1） | 1114 |
| **合計** | **2140** |

出典は文化庁「常用漢字表」（平成 22 年内閣告示第 2 号・2136 字）と文部科学省「学年別漢字配当表」（小学校学習指導要領 2017 年 3 月告示・2020 年度施行・1026 字）。取得と検算の方法は §4。

**中学（L1）が 1114 で、常用漢字 2136 − 教育 1026 = 1110 より 4 字多いのは意図的**である。簡易慣用字体の **剥・叱・填・頬** は常用漢字表の外（正式字体は 剝・𠮟・塡・頰）だが、実際の原稿で使われるのはこちらなので、正式字体と同じ L1 で併載している。外すと符号位置判定に落ちて「一般漢字(L2)＝ルビ候補」に誤分類される。

## 3. `vs furigana` への含意

### 3.1 「基準レベル」からルビ対象を導く

`PLANNED.md` は基準レベルの例として「小4向け＝小5以上／中学以上／常用外のみ」を挙げている。これを本仕様のレベルへ写すと次のようになる。

| 基準の指定 | ルビを振る対象 |
| :--- | :--- |
| 小学 N 年向け | L0 のうち**学年 > N** のもの、および L1・L2・L3・L4 |
| 中学以上向け | L1 以上（＝ L0 以外すべて） |
| 常用外のみ | L2 以上（＝常用漢字表の外） |

### 3.2 学年を取り出す — `KanjiLevels.grade_of`

配当学年は `KanjiLevels.grade_of(char)` で取れる（2026-07-28 追加）。教育漢字なら `1`〜`6`、それ以外は `nil`。

```ruby
KanjiLevels.grade_of('城')   # => 4
KanjiLevels.grade_of('換')   # => nil（中学・L1）
KanjiLevels.grade_of('碍')   # => nil（常用外・L2）
```

`level_of` の戻り値は変えていない（`vs metrics` の集計・表示は不変）。両者の一致は**構造的に保証**されている——`level_of` が `:kyoiku` を返す条件そのものを `grade_of` の非 nil に委ねているため、「`grade_of` が 1〜6 を返す字数の合計 ＝ `level_of` が `:kyoiku` を返す字数」がずれることは起こらない。

```ruby
def level_of(char)
  return :chugaku if table[char] == CHUGAKU
  return :kyoiku if grade_of(char)   # ← ここが唯一の判定点

  jis_level(char)
end
```

この不変条件と学年別の公式字数は `kanji_levels_test.rb` が全字に対して検査している。

### 3.3 読みの生成は本仕様の対象外

レベル判定（どの漢字にルビが要るか）と読みの生成（何と振るか）は別問題で、後者が `vs furigana` の本質的な難所である。`PLANNED.md` に記したとおり、**まさにルビを振りたい稀な漢字（L2〜L4）ほど MeCab が未知語として誤分割・誤読する**ため、全自動は成立しない。本仕様はレベル定義だけを担い、読みの生成方針は `vs furigana` の仕様書で決める。

## 4. データの取得と検算（2026-07-28 に更新）

当初の同梱データは **2020 年度施行より前の配当表**だった（L0 が 1006 字、都道府県名の 20 字が `中学` のまま）。`vs metrics` の統計では 20 字ぶんの誤差にとどまるが、`vs furigana` の「小4向け」では**本来ルビの要らない都道府県名にルビが振られる**ため、実装前に更新した。

**kanjiapi.dev（当初の出典）は使えない。** KANJIDIC2 由来で 2017 年改訂が反映されておらず、`茨` は今も `grade: 8`（常用漢字・小学校外）、grade-4 は 200 字を返す。

代わりに Wikipedia の 2 記事から取得し、次の 3 段階で検算した。

1. **「常用漢字一覧」の本表**から〈通用字体・学年・削除年〉を抽出。削除済み 5 字（勺・錘・銑・脹・匁）を除いて **2136 字**、学年内訳 **80 / 160 / 200 / 202 / 193 / 191 / S 1110** ——公式の字数と完全一致。
2. **「学年別漢字配当表」の記事**から学年別の一覧を独立に抽出し、各節の宣言字数（80/160/200/202/193/191）と一致することを確認。
3. 1 と 2 の学年欄を突き合わせ、**1026 字すべてで一致**することを確認（食い違いゼロ）。

更新の結果:

- **収録字は 2140 字のまま不変**（追加も削除もなし）。変わったのは 57 字の学年ラベルだけ。
- 中学 → 4 年: 20 字（井佐埼奈媛岐岡崎栃梨沖滋潟熊縄茨阜阪香鹿）
- 学年間の移動: 4→5 が 21 字、4→6 が 2 字、5→4 が 4 字（富・徳・群・賀）、5→6 が 9 字、6→4 が 1 字（城）

5→4・6→4 の 5 字（富＝富山、徳＝徳島、群＝群馬、賀＝佐賀/滋賀、城＝宮城/茨城）が都道府県名に必要な字である点まで整合しており、改訂の内容そのものと一致する。

次に更新するときも、**公式字数との一致を検算してから差し替えること**。字数が合わない出典は信用しない。

## 5. スコープ外

- **L2/L3 の細分化**（人名用漢字・表外漢字字体表など）: 現行の JIS 水準による 2 分割で「稀さ」の目安としては足りている。細分化の要望が出たときに再検討する。
- **レベルの設定キー化**（`book.yml` から境界を動かす）: レベルは事実データ（配当表・JIS 水準）であって好みではないため、キーにしない。著者が選ぶのは「基準レベル」（§3.1）だけで、それは `vs furigana` 側の引数・設定として持つ。
