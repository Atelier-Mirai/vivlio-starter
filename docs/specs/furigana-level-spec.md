# 漢字レベル定義（L0〜L4）— `vs metrics` / `vs furigana` 共通

> 作成日: 2026-07-28
> ステータス: **仮**（現状の定義を書き起こしたもの。L0〜L4 は `vs metrics` で実装済み・`vs furigana` は未着手）
> 対象: `PLANNED.md`「`vs furigana`（半自動ルビ付与）」が参照するレベル定義
> 関連: `lib/vivlio_starter/cli/metrics/kanji_levels.rb`（実装）, `lib/vivlio_starter/cli/metrics/data/kyoiku_joyo_kanji.tsv`（同梱データ）, `contents/32-metrics.md`「漢字レベル（ルビ候補）」（著者向け説明）

## 0. なぜこの仕様書があるか

`PLANNED.md` の `vs furigana` の項が「レベル定義は furigana-level-spec 参照＝`vs metrics` と共通の L0〜L4」と書いていたが、その仕様書は書かれていなかった（2026-07-28 に発覚）。

定義の実体は `kanji_levels.rb` の冒頭コメントにあり、`vs metrics` の「漢字レベル（ルビ候補）」として**既に実装・稼働している**。`vs furigana` は同じ定義を共有する前提なので、コード内コメントに埋まったままにせず、両コマンドが参照する 1 箇所へ引き出す。**新しい定義を決める仕様書ではなく、現状の定義を記録し、`vs furigana` を作るときに効いてくる論点を添えたもの**である。

## 1. レベル定義

| レベル | 表示ラベル | 内容 | 判定方法 |
| :--- | :--- | :--- | :--- |
| **L0** | 教育 | 小学校の学年別漢字配当表の漢字 | 同梱データ（学年 1〜6） |
| **L1** | 中学 | 中学で習う常用漢字 | 同梱データ（`中学`） |
| **L2** | 一般(L2) | JIS 第一水準 ∖ 常用漢字（人名・地名など） | 符号位置から算出 |
| **L3** | 専門(L3) | JIS 第二水準（専門的・旧字体） | 符号位置から算出 |
| **L4** | JIS外 | JIS X 0208 に無い漢字（第三水準・補助漢字など） | 変換不能 |

内部のシンボルは `:kyoiku` / `:chugaku` / `:ippan` / `:senmon` / `:gaiji`（`KanjiLevels::LABELS`・`ORDER`）。「L0〜L4」という番号は著者向けの通し番号で、コード上の識別子ではない。

判定は `KanjiLevels.level_of(char)` の 1 箇所に集約されている:

1. 同梱 TSV を引き、値が `中学` なら **L1**、それ以外の値（学年 1〜6）があれば **L0**
2. 表に無ければ EUC-JP へ変換し、第 1 バイトの区が 47 以下なら **L2**、超えれば **L3**
3. EUC-JP に変換できなければ **L4**

**JIS 水準の判定に符号位置を使うのは意図的**で、第一/第二水準の文字表を同梱しなくて済む（JIS X 0208 の区分がそのまま水準の境界になっている）。同梱データは常用漢字の内訳（L0/L1）にだけ必要。

## 3. `vs furigana` への含意

### 3.1 「基準レベル」からルビ対象を導く

`PLANNED.md` は基準レベルの例として「小4向け＝小5以上／中学以上／常用外のみ」を挙げている。これを本仕様のレベルへ写すと次のようになる。

| 基準の指定 | ルビを振る対象 |
| :--- | :--- |
| 小学 N 年向け | L0 のうち**学年 > N** のもの、および L1・L2・L3・L4 |
| 中学以上向け | L1 以上（＝ L0 以外すべて） |
| 常用外のみ | L2 以上（＝常用漢字表の外） |

### 3.2 **学年の粒度は同梱データにあるが、現在は捨てられている**

これが `vs furigana` を作るときに最初に当たる点である。TSV は学年（`1`〜`6`）を保持しているのに、`KanjiLevels.level_of` は

```ruby
return :chugaku if grade == '中学'
return :kyoiku if grade      # ← 1〜6 の区別がここで消える
```

と、教育漢字をすべて `:kyoiku` へ潰している。`vs metrics` は学年別の内訳を表示しないため現状これで足りているが、**上表の「小学 N 年向け」は学年が分からないと判定できない**。`vs furigana` の実装時には、`level_of` とは別に学年を返す入口（例: `KanjiLevels.grade_of(char)`）を足す必要がある。`level_of` の戻り値を変えると `vs metrics` の集計・表示が壊れるため、**既存メソッドの意味は変えないこと**。

### 3.3 読みの生成は本仕様の対象外

レベル判定（どの漢字にルビが要るか）と読みの生成（何と振るか）は別問題で、後者が `vs furigana` の本質的な難所である。`PLANNED.md` に記したとおり、**まさにルビを振りたい稀な漢字（L2〜L4）ほど MeCab が未知語として誤分割・誤読する**ため、全自動は成立しない。本仕様はレベル定義だけを担い、読みの生成方針は `vs furigana` の仕様書で決める。

## 4. 既知の課題（実装前に確認すること）

1. **同梱データの配当表が 2020 年度施行より前の版である。** 都道府県名の 20 字（茨・媛・岡・潟・岐・熊・香・佐・埼・崎・滋・鹿・縄・井・沖・栃・奈・梨・阪・阜）は 2017 年告示・2020 年度施行の配当表で**小学 4 年**に移ったが、同梱データでは全 20 字が `中学`（L1）のままである（2026-07-28 に全数確認）。L0 の字数 1006 も改訂前の値で、現行版は 1026。
   `vs metrics` の統計では 20 字ぶんの誤差にとどまるが、**`vs furigana` の「小4向け」targeting では、本来ルビの要らない都道府県名にルビが振られる**ため実害が出る。データの更新を先に済ませること。
2. **合計 2140 字が常用漢字表の 2136 字と合わない。** 上記の 20 字を移しても差の 4 字は残る。素性の確認が必要。

## 5. スコープ外

- **L2/L3 の細分化**（人名用漢字・表外漢字字体表など）: 現行の JIS 水準による 2 分割で「稀さ」の目安としては足りている。細分化の要望が出たときに再検討する。
- **レベルの設定キー化**（`book.yml` から境界を動かす）: レベルは事実データ（配当表・JIS 水準）であって好みではないため、キーにしない。著者が選ぶのは「基準レベル」（§3.1）だけで、それは `vs furigana` 側の引数・設定として持つ。
