## 0. 決定の一覧（骨格）

| 項目 | 決定 |
| :--- | :--- |
| 出力の形 | `print_pdf` の表紙の形を選ぶキーを 1 つ足す（名前はこの仕様書で決める。値は「表 1 と表 4 を別々に」＝今のまま＝既定、「くるみ」）。入稿先がどちらを求めるかは著者が答えを持つ。閲覧用の `pdf`・`epub`・`kindle` の表紙は変えない |
| 生成物 | `cover_spread_<テーマ>_<判型>_cmyk.pdf`（塗り足しとトンボつき。今の `CropMarksOverlay`・`PrintGeometry` を使う）。くるみを選んだときは、別々の入稿用の表紙は作らない |
| 並び（左から） | 左綴じ: 表 4・背・表 1。右綴じ: 表 1・背・表 4。違いは並びだけで、`traits.binding` を読めば済む |
| 背幅 | 直接の指定（mm。印刷所の計算の値をそのまま書ける）を優先し、無ければ「本文のページ数 ÷ 2 × 本文の紙の厚さ ＋ 表紙の紙の厚さ × 2」で求める。紙の厚さは `book.yml` のキー（1 枚あたりの mm）。どちらも無ければ 🔴 で、書き方と、印刷所の背幅の計算のページを見るよう示す |
| 段 | `build cover spread`。本文のページ数が決まった後（結合の後）に走る。背幅とページ数を出力の一覧に示す |
| 背の中身 | 書名と著者名を縦に組む（左綴じでも背は縦）。地は表 1 の端の色か、`covers/spine_<テーマ>.*` があればそれを使う。背幅が 3mm に満たないときは字を入れず、💡 で知らせる |
| 分冊 | 巻ごとに作る（ページ数が巻で違う） |
| 確かめ | 寸法（幅 ＝ 判型の幅 × 2 ＋ 背幅 ＋ 塗り足し）を `pdfinfo` で、並びを `pdftotext -bbox` で見るテスト。入稿先の検査は、ユーザーが実際の印刷所のテンプレートと重ねて見る |

- キーの名前と値・生成物の名前は著者から見える名前で、S8b で確定したら了承待ちの一覧に載せる（`v2-migration-plan.md` §4.1）。
