# Vivlio Starter 1.0.1

1.0.0 の公開後に見つかった、ささやかな不具合を直した版です。新しい機能も少しだけ足しました。

## 🔧 アップデートの方法

本のプロジェクトで次のコマンドを実行してください。Vivlio Starter 本体と、本の雛形（書体・スタイルシートなど）が新しくなります。

```bash
vs upgrade
```

**技術書典などで PDF を頒布している方へ**: 1.0.0 で組んだ PDF は、Adobe Acrobat Reader で開くと「埋め込みフォントを抽出できません」と表示され、一部の字が抜けることがありました（macOS のプレビューや Chrome では起きません）。`vs upgrade` のあと `vs build` で組み直してください。

## 🐛 直したこと

- 頒布用の PDF を Adobe Acrobat Reader で開くと、キーの書体と、図（数式の日本語・showcase・mermaid）の字の一部を読めずにいたのを直しました。
- コードブロックの見出しに空白を書くと、空白のところで切れていたのを直しました。
- 付録のページで、強調や囲み・コラムの地も付録の色で塗るようにしました。
- `:::{.align-center}`・`:::{.align-right}` の中の段落が、中央・右にそろわなかったのを直しました。
- 角かっこのキー（`〘[〙`・`〘]〙`）や、`:::{.output}` の中の `[arm64-darwin27]` のような角かっこが消えていたのを直しました。
- EPUB が、画像の代替テキストの `"` や、書名の空白で、EPUBCheck のエラーになっていたのを直しました。
- そのほかの細かな修正は [CHANGELOG](https://github.com/Atelier-Mirai/vivlio-starter/blob/master/CHANGELOG.md) をご覧ください。

## ✨ 足したこと

- キーの記法で、Mac の Option（`〘⌥〙`）と Control（`〘⌃〙`）もキーの形で組めるようにしました。
- `vs lint` が、索引の印と読まれてしまう角かっこ（`[arm64-darwin27]` など）を指摘するようにしました。

## 📥 動作要件

1.0.0 と同じです（Ruby 3.4 以上・Node.js 22.12 以上）。テストを Ruby 3.4・4.0 の両方で、実際に本を組むリリースゲートを最新の 4.0 で通しています。
