# Vivlio Starter 1.0.2

同梱の扉絵・節絵の花の絵を、きれいな絵に差し替えた版です。あわせて、扉絵・節絵を作る時間を短くし、細かな不具合を直しました。

## 🔧 アップデートの方法

本のプロジェクトで次のコマンドを実行してください。Vivlio Starter 本体と、本の雛形（同梱の花の絵・書体・スタイルシートなど）が新しくなります。

```bash
vs upgrade
```

作り済みの扉絵・節絵は、次の `vs build` で、新しい花の絵から 1 回だけ作り直されます。

## 🌸 同梱の花の絵をきれいにしました

- 同梱の花の絵 12 枚（`sakura`・`ume`・`tsubaki` など）を、新しい絵に差し替えました。
- 扉絵・節絵を作るとき、元の絵の白い部分（白い花びら）まで透明になっていたのを直しました。濃い色の地に置いても、白い花は白いまま組まれます。絵の縁に出ていた白いにじみも無くなりました。

## ⚡ 扉絵・節絵を作る時間を短くしました

扉絵・節絵を作るとき、十分に大きい絵では waifu2x による拡大を省くようにしました。同梱の絵から扉絵・節絵を作る時間が、1 枚の絵あたり約 30 秒から約 7 秒になります。作るのは、その花の絵を初めて使うときだけです。Vivlio Starter のマニュアル（A4・約 350 ページ）を、キャッシュを消してから組む時間は、約 180 秒から約 165 秒になりました。

幅が 1,920 ピクセルに満たない絵（著者が用意した小さな絵など）は、これまでどおり waifu2x で拡大します。waifu2x が無いことの警告も、拡大が必要な絵のときだけ出すようにしました。

## 🐛 直したこと・変えたこと

- `.md` ファイルを直接ビルドしたとき（`vs build ~/notes/idea.md`）、PDF と圧縮版を、コマンドを実行したディレクトリではなく、原稿と同じディレクトリ（`~/notes/idea.pdf`）に作るようにしました。
- 画像の余白の警告（`{trim=on}` の勧め）で、直し方の行に画像の説明文を全部載せていたのを、`![…]` に縮めて短くしました。
- そのほかの変更は [CHANGELOG](https://github.com/Atelier-Mirai/vivlio-starter/blob/master/CHANGELOG.md) をご覧ください。

1.0.1 と同じです（Ruby 3.4 以上・Node.js 22.12 以上）。動作を確かめた Ruby を 3.4.13・4.0.10 に上げました。テストを両方の版で、実際に本を組むリリースゲートを最新の 4.0 で通しています。
