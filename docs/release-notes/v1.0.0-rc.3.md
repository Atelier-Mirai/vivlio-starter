# vivlio-starter v1.0.0-rc.3

**Release Candidate 3**（2026-08-21）

RC2 から 11 日、102 コミットぶんの改善です。今回は**数式まわりの全面的な作り直し**、**日本語校正の交ぜ書き検出**、**成果物の大幅な軽量化**が三本柱です。いずれも「著者が何もしなくても効く」方向に寄せてあります。

> RC 版は正式版の前段です。機能は出揃っており、以後は不具合の修正を中心に 1.0.0 へ向かいます。

---

## ✨ ハイライト

### 🧮 数式は「見たまま」書けるようになりました

**LaTeX を知らなくても数式が書けます。** `x²` `√(a+b)` `Σ` `a^(p-1) mod p` のように素のまま書けば、ビルド時に TeX へ起こして綺麗に組みます。**原稿に LaTeX は一度も書きません。**

これは親切機能である前に、**現に起きていた無言のデータ欠落の修理**です。MathJax は素の表記をエラーにしないまま壊します。

| 書いたもの | これまでの出力 |
|---|---|
| `x²+y²` | `𝑥+𝑦`（上付きが消える） |
| `H₂O` | `𝐻𝑂` |
| `a・b` | `𝑎𝑏`（中黒が消える） |
| `√2` | 根号の横線が無い |
| `2^(1/3)` | `2` の右肩に `(` だけ |

ビルドは成功し警告も出ないので、著者は刷り上がりを見るまで気づけませんでした。

**バッククォートも数式デリミタとして使えます。** 等幅で本文と区別が付くという理由でバッククォートを使う書き方は実際に多く、`` `√n` `` `` `π(n) ≈ n / ln(n)` `` は数式として組みます。判定は控えめで、`puts` や `array[i]` のようなコードは拾いません。

判定に頼りたくないときは ```` ```math ```` と宣言できます（GitHub と同じ書き方です）。各行を `$$` で囲まなくても `=` の位置で揃います。

**Kindle の数式を作り直しました。** インライン数式は**本文テキスト**へ落とすので、読者が文字を大きくすれば数式も一緒に大きくなります。`√…` も `∑` と上下限も追従します。テキストで表しようがない式は、著者が書いた原文テキストへ落ちるので、こちらも追従します。ディスプレイ数式は総和や積分の組版を保つため画像のままです（行を占有するので崩れません）。

巻末に **数式記法早見表**（付録）を新設しました。ギリシャ文字 24 種・記号 8 分類・関数 38 種を、書きたい形から引けます。

### ✍️ 交ぜ書きを指摘します

`だ円`（楕円）・`ぜい弱`（脆弱）のように、熟語の一部だけをかなで書いた表記を `vs lint` が見つけ、`--fix` で漢字へ直せます。

**辞書を 2 段構成にし、150 語から約 2,000 語へ増やしました。** 第 2 層の約 1,900 語は MeCab があるときだけ効きます。綴りだけでは外せない誤検出があるためで、`う回`（迂回）は「使う回数」「という回答」に紛れますが、MeCab に読ませると「使う｜回数」と語が切れて初めて外せます。**MeCab が無い環境では指摘が減るだけで、誤った指摘は出ません。**

かなで通すと決めた語は `config/textlint_allowlist.yml` に書けば黙ります。表外漢字はすべて開く方針なら、`disabled_rules` に `mazegaki` と書いてルールごと切れます。

### 📦 PDF と EPUB が大幅に軽くなりました

**PDF 97.2 MB → 27.3 MB（−71.9%）／ EPUB 30.5 MB → 18.1 MB（−40.6%）**（本書での実測）。著者の設定は要りません。

効いたのは 3 つです。

- **出力ごとに適した画像形式へ変換** — PDF は WebP を格納できず、渡すと可逆圧縮で膨らみます（素材 280 KB が PDF 内で 1,963 KB に）。JPEG なら素材のサイズがそのまま入ります
- **透過のフラット化** — 透過を抱えたままでは可逆圧縮が効かず、花の見本 12 枚だけで 37.22 MB を占めていたものが、白へ落とすと 6.31 MB になりました
- **過剰な解像度の縮小** — 組んでから実際の表示サイズを測り、必要なぶんまで詰めます。EPUB / Kindle にも版面基準で効きます

**`images/` の画像は書き換えません。** 派生は `.cache/` の中だけに作られます。

## 🔧 その他の改善

### 執筆・校正
- **語の途中に入った強調記法で校正がすり抜けていた**のを直しました。`結**合し**直した` が誤検出になり、`あいさつ**文**` は取りこぼしていました。判定の入力を「読者が見る文字列」に揃えています
- **`vs lint` が数式を日本語の文として読んでいた**のを直しました。数式の中の半角括弧が「全角にせよ」と指摘され、`--fix` を当てると数式が壊れていました
- **`vs upgrade` が、著者の見ていない変更まで適用していた**のを直しました。別の場所を変えた競合は 3-way マージで自動合流し、競合 diff には色とどちらが自分のファイルかの凡例が付きます
- 用語集リンク（†）を**章ごとの初出だけ**に絞りました（本書で 571 個 → 167 個）

### ビルド
- **単章ビルドを全章ビルドのステップ表から導出**するようにしました。2 つの表を手で維持していたため「単章では出るのに全章では出ない」が繰り返し起きていた構造を解消しています
- **入稿用 PDF を `vs pdf:compress` にかけようとすると引き止めます**。圧縮すると 150 dpi へ落ち、印刷所の要求を下回るためです
- 画像の WebP 変換から「22 倍の崖」を外しました（`method` 6 → 4。時間 22 倍に対しサイズ差 1.5%）
- `--no-resize` と画像品質プリセット（`--high` / `--medium` / `--low`）を `vs build` から撤去しました。並列化と mtime 判定で謳うほどの効果がなくなったためです

### 不具合修正
- **`vs index:apply` が、登録済みの語を手書きの定義文ごと消していた**のを直しました。`[-i]`（索引から外す／用語集には残す）が残す語まで除外リストへ書き込み、次回以降の実行がそれを削除で解決するという**時限式**でした。既に矛盾を抱えたプロジェクトは、次の `apply` で自動的に正しい状態へ戻ります
- **目次・索引・用語集が `lang="ja"` のベタ書き**でした。英語の本でもこの 3 ページだけ日本語と申告していました
- **A4 以外の判型でこの 3 ページが A4 で組まれていた**問題を、B5・A5 の全章ビルドで確認しました（全ページが指定判型であることを実測）
- 引用（`>`）の中のコードブロックが「地の文」として扱われていたのを直しました
- 前書き・後書きに `###` を書くと入稿用 PDF に Type 3 フォントが混入していたのを直しました
- `vs` の警告とエラーが**一度も著者へ届いていなかった**のを直しました（`RUBYOPT=-W0` が `warn` の出力ごと捨てていました）

## ⚠️ 既知の不具合
- 長い見出しの折返し位置が PDF と EPUB / Kindle で一致しません（組むエンジンが異なるため。`heading_chars` を実長以上にすれば差は出ません）。
- EPUB の表紙画像が一回り小さく見える場合があります（カバーの想定比 1:1.6 と本文の判型比の差によるもの）。
- Kindle 実機での最終確認は継続中です。Kindle Previewer での表示は確認済みです。

> RC2 で挙げていた「Kindle の表内インライン数式のサイズが不安定」は、今回の数式の作り直しで**解消**しました。表の中も同じ経路でテキスト化されるため、「表内に数式を置かない」という運用回避は不要になりました。

## 📥 インストール / 動作要件
- Ruby **3.4 以上**（3.4.10 と 4.0.6 で動作確認）。
- macOS + Homebrew 環境を主対象としています。外部ツールの自動導入（`vs doctor --fix`）はこの環境でのみ動作します。
- 交ぜ書き検出の第 2 層を使うには MeCab が要ります（`vs doctor --fix` で導入できます）。

```bash
gem install vivlio-starter --pre   # プレリリース版のため --pre が必要です
```

すでに RC2 をお使いの場合は `gem update vivlio-starter --pre` で更新できます。プロジェクト側の雛形と外部ツールは `vs upgrade` で追随します。
