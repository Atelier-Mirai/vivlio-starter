# 書籍紹介カードに書誌（著者・出版社・発行年）を載せる

> 状態: 実装済み（2026-10-12。query-stream 側は未公開・1.5.0 で公開）
> 発端: ユーザー提案（2026-10-12）。市販の書籍を紹介するとき、著者・出版社・発行年も載せたい。

## 1. いまの姿

- `:::{.book-card}` は、画像を左の表紙に、`**…**` の行を書名にし、**残りの行をすべて「説明」**として組む。
  著者や出版社の行を書いても、説明と同じ大きさ・色で並ぶだけ。
  94 章は `リブロワークス (著), Vivliostyle (監修)<br><br>` と `<br>` を手で入れて、説明との間を空けている。
- QueryStream のテンプレートは、**行の中のキーが 1 つでも空なら行ごと消す**。
  `= author.name 著／= publisher／= year 年` と 1 行に書くと、発行年の分からない本では著者まで消える。
  雛形の `_physics_book.md` の `= author.name 著（= year年）` も、発行年が無いと著者名が出ない。

## 2. QueryStream: 空のキーを含む部品だけを消す（query-stream 1.5.0）

`TemplateCompiler.expand_variables` を直す。新しい書き方は足さない。

### 2.1 規則

1. 対象は**変数（`= key`）が 2 つ以上ある行**だけ。変数が 1 つの行は今までどおり、空なら行ごと消す。
2. **表の行（`|` で始まる行）は対象にしない。** セルを消すと列がずれるので、今までどおり行ごと消す。
3. 変数を含む**括弧**（`（…）`・`(…)`）は、それだけで 1 つの部品にする。中のキーが 1 つでも空なら、括弧ごと（直前の空白も）消す。
4. 括弧の外は、**区切り**で部品に分ける。区切りは `／`・`・`・`、`・`，`・`,` と、前後に空白のある半角の `/`（` / `）。
   前後の空白は区切りに含める。空白なしの半角の `/` を区切りにしないのは、URL（`https://example.com/books/= id`）を割らないため。
5. 空のキーを含む部品だけを消し、区切りを 1 つ詰める。変数に付いた言葉（`著`・`年`）は、変数と一緒に残るか、一緒に消える。
   残った部品どうしは、前の部品の後ろにあった区切りでつなぐ。
6. **行頭の Markdown の目印**（箇条書きの `- `・`* `・`+ `、番号の `1. `、引用の `> `、見出しの `# `）は、部品が消えても残す。
7. 変数を含む部品が 1 つも残らなければ、今までどおり行ごと消す。
8. キーがすべて埋まっている行の出力は、今までと 1 文字も変わらない。

### 2.2 例

`= author.name 著／= publisher／= year 年`

| データ | 出るもの |
|---|---|
| 全部ある | 高橋征義 著／SBクリエイティブ／2019 年 |
| 発行年が無い | 高橋征義 著／SBクリエイティブ |
| 出版社が無い | 高橋征義 著／2019 年 |
| 著者だけ | 高橋征義 著 |
| 全部無い | 行ごと消える |

`= author.name 著（= year年）`（雛形の `_physics_book.md`）

| データ | いま | 直したあと |
|---|---|---|
| 発行年が無い | 行ごと消える | 高橋征義 著 |

### 2.3 限り

- 部品の中で装飾を閉じる（`**= title**／= year` は動くが、`**= title／= year**` のように区切りをまたぐ装飾は、部品が消えると閉じ側を失う）。
- 区切りの文字が説明の中に出る行（`= a は、= b と同じ`）は、読点で部品に分かれる。
  キーがすべて埋まっていれば出力は変わらないので（§2.1 の 8）、困るのは片方が空のときだけ。

## 3. 書籍紹介カード: 書名の後の最初の段落を書誌として組む（vivlio-starter）

### 3.1 規則

- 書名の後に**段落が 2 つ以上**あるとき、最初の段落を書誌として `<p class="book-meta">` にする。
  中は今と同じく 1 行ずつ改行する。役割（著・監修・訳・編）は本によって違うので、項目名は決めない。
- **段落が 1 つだけのカードは今と同じ**（説明として組む）。今あるカードは書き直さなくても変わらない。

```markdown
:::{.book-card}
![](vivliostyle_introduction.webp)
**Web技術で「本」が作れるCSS組版Vivliostyle入門**
リブロワークス 著／Vivliostyle 監修
C&R研究所・2023 年

簡単に説明すると、CSS組版とは……
:::
```

出力（`format_book_card_inner_html`）:

```html
<div class="book-card">
  <img src="…">
  <div class="book-info">
    <p class="book-title">Web技術で「本」が作れるCSS組版Vivliostyle入門</p>
    <p class="book-meta">リブロワークス 著／Vivliostyle 監修<br>C&amp;R研究所・2023 年</p>
    <div class="book-description">
      <p>簡単に説明すると、CSS組版とは……</p>
    </div>
  </div>
</div>
```

### 3.2 見た目（`components.css`）

- `.book-meta`: 説明より一回り小さく（10pt）、薄めの色。書名との間は詰め、説明との間は空ける。
- Kindle（`body.vs-kindle .book-meta`）: 色を `var()` でなく実際の色の値で書く。

### 3.3 データ・テンプレート・原稿

- `templates/_book.md`: 書誌の行 `= author.name 著／= publisher／= year 年` を足し、説明との間に空行を置く。
  著者・出版社・発行年がすべて無い本では、書誌の段落ごと消えて説明だけになり、今と同じ組み方になる。
- `data/books.yml`: 2 冊に `publisher`・`year` を足す（『たのしいRuby 第6版』SBクリエイティブ・2019 年、『はじめてのC 改訂第5版』技術評論社・2008 年）。
- 23 章: 書誌の段落の書き方と表示例を足す。
- 26 章: テンプレートとデータの例を新しい形にし、「空のキーを含む部品だけが消える」ことを書き足す（§2）。
- 94 章: `<br><br>` をやめ、空行で書誌と説明を分ける。
- 雛形の `_physics_book.md` は変えない（§2 で、発行年の無い本でも著者が出るようになる）。
