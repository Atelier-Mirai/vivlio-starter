# 数式表示チェック

この章は**数式の表示を実機で確かめるための検査ページ**です。書籍の一部ではありません。
`plain-math-notation-spec.md` §3-2 の経路表の各マスを 1 つずつ踏むように並べてあります。

::: {.note}
**使い方**

```
rake math:check          # contents/ へ置き直してビルド（rake reinstall は要りません）
rake math:check:clean    # 終わったら複製を取り除く
```

1. Kindle Previewer 3 で開き、**文字の大きさを最小と最大に振る**
2. 下の各節の「見えるべきもの」と照らす

事前に 1 度だけ `config/catalog.yml` に `81-math-check` を、`config/book.yml` の
`output.targets` に `kindle` を入れておきます（未設定なら `rake math:check` が知らせます）。
:::

## 1. インライン数式 — 文字の大きさに追従すること

Kindle ではインライン数式を**本文テキスト**にします。文字を大きくすると数式も一緒に大きくなるのが正解です。**ここで数式だけ大きさが変わらなければ不合格**です。

### 1-1. 整形済みのテキストになるもの

変数が斜体、指数が真の上付きで出ます。

質量とエネルギーの関係は $E=mc^2$ です。三平方の定理は $x²+y²=z²$ と書けます。
水の分子式は $H₂O$、落下距離は $\frac{1}{2}gt^2$、指数は $10^{-34}$ です。

**見えるべきもの**: 指数が小さく上に付き、変数が斜体。文字の大きさが本文に追従する。{.aki}

### 1-2. 書いたとおりの文字になるもの

整形しきれない式は、**著者が書いたそのままの文字**で出ます。画像ではないので追従します。

第一宇宙速度は $√(GM/R)$、標準偏差の分子は $Σ(x−μ)²$ です。
プランク定数は $6.626×10⁻³⁴$、電子の質量は $9.109×10⁻³¹$ kg です（``×`` は整形の対象外）。
フェルマーの小定理は $a^(p-1) mod p$、三角関数の基本公式は $sin²θ + cos²θ$ です。
固有値の方程式は $λ² − 1$、面積は $a × b ÷ c$ で求まります。

**見えるべきもの**: ``√(GM/R)`` のように書いたままの形。**追従する**（画像ではない）。{.aki}

### 1-3. 画像のまま残るもの

LaTeX で書かれた複雑な式だけは画像です。ここは追従しません（既知の制限）。

根号は $\sqrt{2}$、斜辺は $\sqrt{a^2+b^2}$、分数は $\frac{a+b}{2}$ と書きます。

**見えるべきもの（Kindle）**: `√2`・`√(a²+b²)`・`(a+b)/2` のテキスト。追従する。
**とくに `(a+b)/2` の括弧**——これが無いと `a + b/2` に読めてしまいます。
**見えるべきもの（PDF）**: 綺麗に組まれた数式画像。文字を変えても大きさは変わらない（仕様）。{.aki}

インラインの大型演算子は、TeX の決まりでは上下限が記号の横へ寄って潰れます（実測 2.6ex）。
そこで `\limits` を挿し、**上下へ開いて二行分の高さ**を取るようにしています（5.4ex）。
**Kindle ではテキストになる**ので、そちらは横に付きます。

総和は $\sum_{i=1}^{n} i$、積分は $\int_{0}^{1} x^2 dx$、極限は $\lim_{n \to \infty} a_n$。

**見えるべきもの（PDF・EPUB）**{.aki}

- `∑` — 上下限が**記号の上下へ開き、二行分の高さ**を取る（5.4ex。数学書と同じ組み方）
- `∫` — 上下限は**横のまま**、記号だけ大きくなる（3.1ex）。積分はそれが組版の慣習
- `lim` — 上下限は**横のまま**。上下へ開いても 3.2ex で本書の行送り 1.6em（≒3.5ex）に
  収まってしまい行が押し開かれず、しかも `lim` は文字列なので display style でも
  大きくならない（`\displaystyle` でも同じ 3.2ex）。横に置くほうが `lim n→∞ aₙ` と読める

**見えるべきもの（Kindle）**: どれもテキスト。`∑` は右下・右上に、`lim` は右下に上下限が付き、
記号の後ろに細空白が入る（`lim n→∞ aₙ`）。文字の大きさに追従する。{.aki}

同じ式をディスプレイ数式として置くと、こうなります。{.aki}

$$\sum_{i=1}^{n} i$$

$$\int_{0}^{1} x^2 dx$$

$$\lim_{n \to \infty} a_n = 0$$

$$\lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = e$$

**見えるべきもの（PDF・EPUB）**{.aki}

- `∑` `∫` — 上下限が記号の上下・横に大きく開く（インライン版と見比べてください）
- `lim` — `n → ∞` が **`lim` の下**へ入る（3.2ex）。インラインでは横に付くので、そこが違い
- 最後の式 — `1/n` が**本物の分数**（横線で上下に分かれる）になり、5.5ex まで開く。
  インラインだと `1/n` は斜線のままです

**総和・積分・極限・大きな分数はディスプレイ数式で書く**のが正解です。{.aki}

**見えるべきもの（Kindle）**: ディスプレイ数式は**画像**です。文字の大きさを変えても
大きさは変わりませんが、行を占有するので崩れません（`∑` や `∫` の組版を保つための仕様）。{.aki}

## 2. ディスプレイ数式 — 画像で組版が保たれること

独立行の数式は Kindle でも画像です。`Σ` や `∫` の組版を保つためで、行を占有するので大きさが変わらなくても崩れません。

オイラーの等式。

$$e^{i\pi} + 1 = 0$$

素数定理と、円の面積。

$$π(n) ≈ n / ln(n)$$

$$面積 = π × r²$$

総和と積分。

$$Σ(k=0 to ∞) 1/k²$$

$$∫[0, π/2] sin(x) dx$$

複数行は関係演算子の位置で揃います。

$$\begin{aligned}
\cos θ &= 1 - θ²/2! + θ⁴/4! - θ⁶/6! + ... \\
\sin θ &= θ - θ³/3! + θ⁵/5! - θ⁷/7! + ...
\end{aligned}$$

**見えるべきもの**: 中央に大きく組まれた数式。根号の横線・総和記号・積分記号が正しい形。{.aki}

## 3. バッククォートで書いた数式

数式デリミタを使わずバッククォートで囲んだ式も、中身が数式なら組まれます。

約数は `√n` 以下と `√n` 以上が対になります。素数の個数は `π(n) ≈ n / ln(n)` で近似できます。
RSA の暗号化は `平文^e mod n`、離散対数は `g^a mod p` です。

言語を書かないコードブロックはディスプレイ数式になります。

```
X_k = Σ x_n・e^(-2πikn/N)
```

```
GCD(a, b) × LCM(a, b) = a × b
```

**見えるべきもの**: どれも数式として組まれている。``平文^e mod n`` も、変数名が日本語なだけの式なので組まれる（`^` という強いしるしがあるため）。{.aki}

## 4. 数式にならないこと（誤変換の確認）

ここが**数式になっていたら不合格**です。等幅のコードのまま出ていることを確かめてください。

コードは `puts "hello"`、配列は `array[i]`、べき乗は `height_m**2` と書きます。
`Complex.polar` や `divisor * divisor <= limit` もコードです。

二重のバッククォートで囲めば、数式らしい中身でもコードのままです。``√n`` ``E=mc^2`` ``Σx²``

```ruby
# 言語を書いたコードブロックは常にコード
value = Math.sqrt(2) ** 2
```

**見えるべきもの**: 上の 3 行はすべて等幅のコード。数式として組まれていない。{.aki}

## 5. 日本語を含む数式

日本語を明示的に `$…$` で囲んだ場合は組みます（PDF ではフォントを埋め込むので Type 3 になりません）。

$$下限 = p̂ − 1.96 × √( p̂(1−p̂) / n )$$

$$攻撃力 = 兵士数 × 訓練度$$

**見えるべきもの**: 日本語が本文と同じ書体で、文字化けや空白抜けがない。{.aki}
