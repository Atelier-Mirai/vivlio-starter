# 索引の明示記法

:::{.chapter-lead}
`[用語]` / `[用語|読み]` の明示記法を、記号・タグ・数字まで含めて並べます。**索引に載せたいものが、記法として解釈されて消えたり、別の要素に化けたりしないこと**を見ます。
:::

## 素直な語

[HTML]は、文書構造を記述します。

[基本情報技術者]とは、IT資格の中で最も基礎的な資格です。

[コンピュータ]は、計算機の一種です。

[引数|ひきすう]は、関数に与える値です。

## 数字

[404]は、ページが見つからないことを示すHTTPステータスコードです。

[500]は、サーバーエラーを示すHTTPステータスコードです。

## 記号・演算子

**ここは Markdown のリンク記法や強調記法と紛らわしい形です。** 角括弧ごと消えたり、リンクとして解釈されたりしてはいけません。

[!]は、否定演算子です。

[&&]は、論理積演算子です。

[||]は、論理和演算子です。

[|]は、ビット和演算子です。

[&]は、ビット積演算子です。

## タグを索引語にする

**ここが 2026-08-11 に再発を確認した箇所です。** タグの形をした語を索引に載せたいだけなのに、**本物の要素として組まれてしまう**という不具合がありました。

`[<h1>]` が `<h1>` 要素になると、章見出しとして登録され、目次と PDF アウトラインまで汚染されます。実際に「は、見出しタグです。」という章が目次に現れました。

[!DOCTYPE]は、文書の種類を示すHTMLの宣言です。

[<h1>]は、見出しタグです。

[</h1>]は、閉じタグです。

[<img>]は、画像を埋め込むタグです。

## 索引にしてはいけないもの

脚注の記法は索引語ではありません[^1]。

[^1]: この脚注が索引語として拾われていたら失敗です。

## 読み指定の境界

[通常|つうじょう]は、読みを 1 本の縦棒で区切ります。

[縦棒が2本|よみ|よけい]は、区切りが 2 本あるためリテラル扱いになります（索引語にはなりません）。

[|よみだけ]は、用語部分が空なのでリテラル扱いです。

[よみなし|]は、読み部分が空なのでリテラル扱いです。
