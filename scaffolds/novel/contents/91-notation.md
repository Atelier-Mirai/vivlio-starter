# 記法の見本

　小説で使う書き方を並べます。それぞれ、原稿の書き方を囲みに示し、その後に組み上がりを置きます。

## ルビ

　ルビは、親文字と読みを波括弧の中に縦棒で区切って書きます。

```
{邂逅|かいこう}を果たした。
```

　{邂逅|かいこう}を果たした。

　小説投稿サイトの書き方も、そのまま読みます。縦棒（半角・全角）から《の前までが親文字です。縦棒を書かなければ、《の直前の漢字の並びが親文字になります（読みが仮名だけのとき）。

```
|魔導書《グリモワール》を開く。図書室《としょしつ》は静かだ。
```

　|魔導書《グリモワール》を開く。図書室《としょしつ》は静かだ。

　ルビにせず《をそのまま組むときは、縦棒の後に《を書きます。

```
題は|《春の雨》という。
```

　題は|《春の雨》という。

## 傍点

　傍点は、角括弧で囲んだ字に `.sesame` を付けて書きます。投稿サイトの書き方の《《》》も読みます。

```
[ここ]{.sesame}が肝心だ。《《決して》》忘れてはならない。
```

　[ここ]{.sesame}が肝心だ。《《決して》》忘れてはならない。

## 縦中横

　半角の数字の 1〜2 桁と、半角の「!?」「!!」は、自動で縦中横に組みます。

```
12月24日の夜、彼は叫んだ。「本当に!?」
```

　12月24日の夜、彼は叫んだ。「本当に!?」

　英字を立てて組むときは、角括弧で囲んだ字に `.tcy` を付けます。半角の数字の 3 桁以上は横に倒れて組まれるので、漢数字か全角の数字で書きます。

```
[AI]{.tcy}が答えた。代金は三百円だった。
```

　[AI]{.tcy}が答えた。代金は三百円だった。

## 挿絵

　行の間に置く挿絵は、画像の書き方で書きます。幅は `width=` で指定します。1 ページを使う挿絵には `.full-page` を付けます。作品の章の山猫軒の絵が行の間の挿絵、扉の絵が 1 ページを使う挿絵です。

```
![山猫軒](images/11-chumon/yamanekoken.svg){width=70%}
![かぎ穴からのぞく二つの青い眼玉](images/11-chumon/door.svg){.full-page}
```

## 脚注

　脚注は、本文に合印を書き、段落の後に注の文を書きます。縦書きでは、注はページの左端に組まれます。

```
山猫軒は西洋料理店である[^1]。

[^1]: 看板には英字でも名前が書いてある。
```

　山猫軒は西洋料理店である[^1]。

[^1]: 看板には英字でも名前が書いてある。

## 場面の区切りと改ページ

　場面を区切るときは、行に `* * *` だけを書きます。1 行の空きになります。ページを改めるときは、行に `@pagebreak` だけを書きます。

## 段落と字下げ

　段落の頭は、組むときに 1 字下がります。括弧で始まる段落（会話文）は下げません。投稿サイトの書き方のとおり、段落の頭に全角空白を書いてもかまいません（組むときに落とします）。段落の間に空行を入れずに 1 行ずつ書いた原稿は、1 行を 1 段落として組みます。

　原稿の書き方は `vs lint` で確かめます。三点リーダーやダッシュが一つだけのところ、「！」「？」の後に全角空白が無いところ、段落の頭の全角空白がそろっていないところなどを示します。
